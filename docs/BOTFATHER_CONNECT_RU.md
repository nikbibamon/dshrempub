# DSHREM и свой Telegram-бот: безопасное подключение

Текущий статус: **заявка на клиентский пилот**, а не автоматическое подключение. Действующий DSHREMBOT обслуживает только оператора Tvijo. Не отправляйте токен своего бота в публичную форму, Telegram-чат, issue, письмо или репозиторий.

1. Установите [публичный VS Code preview](https://github.com/nikbibamon/dshrempub/releases/tag/v0.1.1-preview.1) либо ознакомьтесь с терминальным клиентом в [README](../README.md). Доступ к сервису выдаётся оператором; сам пакет не создаёт платный аккаунт и не включает бесплатные токены.
2. Откройте [@BotFather](https://t.me/BotFather) в Telegram, отправьте `/newbot`, задайте имя и уникальный username. BotFather выдаст токен. Храните его как пароль; при утечке перевыпустите через BotFather. [Официальная инструкция Telegram](https://core.telegram.org/bots/tutorial).
3. На [странице DSHREM + бот](https://tvijo.com/static/dshrem-platform-ru-20261018.html) нажмите «Заявка на пилот бота». В форме Tvijo опишите одну задачу, @username бота, нужные read-only проверки сервера и желаемый лимит. **Токен, SSH-ключи, пароли и ключи моделей туда не вставляйте.**
4. После создания изолированного клиентского пространства Tvijo предоставит защищённый способ ввода токена. До появления и проверки этого способа токен остаётся только у вас. Будущий коннектор должен проверить владельца, Bot API `getMe`, отдельный webhook secret, возможность отзыва токена и изоляцию задач.
5. Серверное управление включается отдельно: сначала только чтение статуса, затем явно разрешённые хосты и команды. Действия, меняющие сервер, требуют отдельного одобрения. Общий операторский рой и CLI-подписки не передаются клиентам.

Предлагаемый пилотный предел **$10** пока не является действующей оплатой или счётом. Условия цены, учёта токенов, остановки на лимите, хранения данных и возвратов должны быть согласованы до платной работы. [Политика данных](../PRIVACY.md) описывает текущий preview; отдельные условия для клиентского бота будут опубликованы до запуска.
