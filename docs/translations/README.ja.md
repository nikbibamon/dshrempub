# Tvijo DSHREM — タスクから検証済みの結果まで

[English](README.en.md) · [Русский](README.ru.md) · [All languages / Все языки](../../README.md#read-the-introductory-guide-in-your-language)

Tvijo は、ブラウザワークスペース、VS Code 拡張機能、ターミナルツールを共通の開発ワークフローの周囲にまとめます。タスクを記述し、その実行ホストと権限を選択し、変更内容を確認し、結果を承認するために使用した証拠を保持します。このガイドは製品を紹介するものです。CLI については、リポジトリの技術 README とコマンドリファレンスが引き続き正式な情報源です。

## 使い慣れたワークスペースから始める

[DSHREM](https://dsh.tvijo.com/) を開くか、[VS Code 拡張機能とターミナルの手順](https://dsh.tvijo.com/download)を入手するか、[設定の説明](https://dsh.tvijo.com/knowledge/settings-explained)を読んでください。サービスがサポートするアカウントフローでサインインします。プロバイダーの API キーを共有プロンプト、公開 issue、リポジトリに貼り付けないでください。

Node.js CLI には Node 22 以降が必要です。ローカルのチェックアウトから:

```sh
npm install -g .
dsh login
dsh doctor
dsh chat
```

コマンドは `dshrem` としても利用できます。このリモートチャット CLI は、提案されたツールを表示するだけで実行はしません。ローカルの編集とコマンド実行は VS Code Agent または明示的に設定されたホストランタイムに属し、それぞれ別の権限を持ちます。[CLI ヘルプ](https://github.com/nikbibamon/dshrempub/blob/main/docs/HELP.md)を参照してください。

## 選択肢を理解する

**証拠優先 (Evidence first)** は、裏付けのある事実と仮定を区別します。**計画と確認 (Plan and check)** は短い計画を求め、結果をリクエストと照合します。**回答をレビューする (Review the answer)** は下書きに異議を唱えます。別のレビュアーが明示的に割り当てられていない限り、これは自己レビューです。これらの手法はいずれも正しさやトークン使用量の削減を保証するものではありません。

タスクプリセットは、再利用可能な指示とチェックリストを追加します。追加のモデルメモリを作成するものではありません。より大きなコンテキストコレクションであっても、サービスとモデルのリクエスト制限に収まる必要があります。高度な controller、Python、state のパスは、選択された拡張機能ホストを指します。Remote SSH では、それがリモートサーバーです。

## 役立つ場合にはチームで作業する

AGENTROY チームは、コーディネーター、実装者、レビュアーにそれぞれ異なる責務を割り当てます。ホストポリシーは、DSHREM ds41f とアカウントベースの Codex または Claude ツールを、任意のアーキテクチャレビューとともに要求する場合があります。利用可否は、インストールされたランタイム、アカウントアクセス、選択されたポリシーに依存します。サブスクリプションがない場合が、通知なしに有料 API 呼び出しになってはなりません。

3 から 6 の役割は組織上の選択であり、品質の公式ではありません。レビュアーには正確な成果物のバージョンとテストの証拠が必要です。モデルが合意していても、重大なチェックの失敗は承認を阻止します。[エージェントチームと可視化されたコスト](https://dsh.tvijo.com/knowledge/agentroy-teams-and-costs)を読んでください。

## 不確実性を隠さずに再開する

デタッチされたサーバー側の tmux セッションは、ノートパソコンや携帯電話が切断された後も継続できます。電源が切れたローカルコンピューターでの作業は継続できません。サーバー障害、メモリ不足、ストレージの損失は、依然として復旧が必要です。保存されたタスク ID に再接続し、さらなる作業を始める前にその最後に確認されたイベントを確認してください。結果が不明な課金対象のリクエストを盲目的に繰り返さないでください。[切断と復旧](https://dsh.tvijo.com/knowledge/durable-work-and-recovery)を参照してください。

## コストとデータを可視化しておく

承認された見積もり、タスク上限、予約額、使用量の領収書を確認してください。8% のサービス手数料は、別途開示される費用の前に、USD1.00 のプロバイダー利用料を USD1.08 にします。これは例であり、価格の提示ではありません。サブスクリプションの割り当て、プロバイダーの請求、サーバーリソースはそれぞれ別の制限です。追加の予算には明示的な選択が必要です。

ローカル CLI の認証情報ファイルは所有者のみの権限を使用します。これらの権限は暗号化でもバックアップでもありません。ナレッジのアップロードは明示的に行われます。プライベートファイルは公開のハンドオフリンクに入れるべきではありません。[プロンプトのハンドオフ](https://dsh.tvijo.com/knowledge/prompt-handoffs)では、レビュー済みのタスクを別のツールにコピーする方法を説明しています。

このリポジトリのパッケージは現在 `UNLICENSED` とマークされています。公開しても再利用の権利は付与されません。再配布する前に、現在のパッケージメタデータとライセンス通知を確認してください。翻訳は導入ガイドであり、DSHREM で生成され、構造の一貫性が確認されています。技術的な相違点については英語版が基準です。
