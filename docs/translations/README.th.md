# Tvijo DSHREM — จากงานหนึ่งสู่ผลลัพธ์ที่ผ่านการตรวจสอบ

[English](README.en.md) · [Русский](README.ru.md) · [All languages / Все языки](../../README.md#read-the-introductory-guide-in-your-language)

Tvijo รวมพื้นที่ทำงานบนเบราว์เซอร์ ส่วนขยาย VS Code และเครื่องมือในเทอร์มินัลไว้รอบ ๆ เวิร์กโฟลว์การพัฒนาที่ใช้ร่วมกัน อธิบายงาน เลือกโฮสต์สำหรับการประมวลผลและสิทธิ์การเข้าถึง ตรวจดูการเปลี่ยนแปลง และเก็บหลักฐานที่ใช้ในการยอมรับผลลัพธ์ คู่มือนี้เป็นการแนะนำผลิตภัณฑ์ ส่วน README ทางเทคนิคและเอกสารอ้างอิงคำสั่งของรีโปซิทอรีถือเป็นแหล่งอ้างอิงหลักสำหรับ CLI

## เริ่มต้นด้วยพื้นที่ทำงานที่คุณต้องการ

เปิด [DSHREM](https://dsh.tvijo.com/) ติดตั้ง[ส่วนขยาย VS Code และอ่านคำแนะนำสำหรับเทอร์มินัล](https://dsh.tvijo.com/download) หรืออ่าน[คำอธิบายการตั้งค่า](https://dsh.tvijo.com/knowledge/settings-explained) ลงชื่อเข้าใช้ผ่านขั้นตอนบัญชีที่บริการรองรับ ห้ามวางคีย์ API ของผู้ให้บริการลงในพรอมป์ตที่แชร์ต่อกัน public issue หรือรีโปซิทอรี

CLI บน Node.js ต้องใช้ Node 22 ขึ้นไป จากเชกเอาต์ในเครื่อง:

```sh
npm install -g .
dsh login
dsh doctor
dsh chat
```

คำสั่งนี้ยังใช้ได้ในชื่อ `dshrem` ด้วย CLI แชทระยะไกลนี้จะแสดงเครื่องมือที่แนะนำโดยไม่ดำเนินการใด ๆ การแก้ไขไฟล์และการรันคำสั่งในเครื่องเป็นหน้าที่ของ VS Code Agent หรือโฮสต์รันไทม์ที่ตั้งค่าไว้อย่างชัดเจน ซึ่งมีสิทธิ์แยกต่างหาก ดู[วิธีใช้ CLI](https://github.com/nikbibamon/dshrempub/blob/main/docs/HELP.md)

## ทำความเข้าใจตัวเลือกต่าง ๆ

**หลักฐานมาก่อน** แยกข้อเท็จจริงที่มีข้อมูลรองรับออกจากข้อสันนิษฐาน **วางแผนและตรวจสอบ** ขอให้มีแผนสั้น ๆ และตรวจสอบผลลัพธ์เทียบกับคำขอ **ทบทวนคำตอบ** เป็นการตั้งคำถามกับฉบับร่าง ซึ่งเป็นการทบทวนด้วยตัวเอง เว้นแต่จะมีการมอบหมายผู้ตรวจสอบแยกต่างหากอย่างชัดเจน วิธีเหล่านี้ไม่มีวิธีใดรับประกันความถูกต้องหรือการใช้โทเคนที่น้อยลง

พรีเซ็ตงานจะเพิ่มคำแนะนำและเช็กลิสต์ที่ใช้ซ้ำได้ โดยไม่ได้สร้างหน่วยความจำของโมเดลเพิ่มเติม คอลเล็กชันบริบทที่ใหญ่ขึ้นยังคงต้องอยู่ในขีดจำกัดคำขอของบริการและของโมเดล เส้นทางขั้นสูงของ controller, Python และ state จะอ้างถึงโฮสต์ของส่วนขยายที่เลือกไว้ ใน Remote SSH โฮสต์นั้นคือเซิร์ฟเวอร์ระยะไกล

## ทำงานเป็นทีมเมื่อเหมาะสม

ทีม AGENTROY กำหนดบทบาทที่แตกต่างกันให้กับผู้ประสานงาน ผู้ลงมือทำ และผู้ตรวจสอบ นโยบายของโฮสต์อาจร้องขอ DSHREM ds41f และเครื่องมือ Codex หรือ Claude ที่ผูกกับบัญชี พร้อมการทบทวนเชิงสถาปัตยกรรมซึ่งเป็นทางเลือก ความพร้อมใช้งานขึ้นอยู่กับรันไทม์ที่ติดตั้ง การเข้าถึงบัญชี และนโยบายที่เลือก การสมัครสมาชิกที่ไม่มีอยู่ต้องไม่กลายเป็นการเรียก API ที่มีค่าใช้จ่ายโดยไม่แจ้งให้ทราบ

บทบาทสามถึงหกบทบาทเป็นทางเลือกด้านการจัดองค์กร ไม่ใช่สูตรรับประกันคุณภาพ ผู้ตรวจสอบต้องมีเวอร์ชันของอาร์ติแฟกต์และหลักฐานการทดสอบที่ตรงกัน การตรวจสอบที่ล้มเหลวอย่างร้ายแรงจะขัดขวางการยอมรับผลลัพธ์ แม้โมเดลจะเห็นตรงกันก็ตาม อ่าน[ทีมเอเจนต์และค่าใช้จ่ายที่มองเห็นได้](https://dsh.tvijo.com/knowledge/agentroy-teams-and-costs)

## ทำงานต่อโดยไม่ปิดบังความไม่แน่นอน

เซสชัน tmux ที่แยกทำงานบนฝั่งเซิร์ฟเวอร์สามารถทำงานต่อได้หลังแล็ปท็อปหรือโทรศัพท์ตัดการเชื่อมต่อ งานบนคอมพิวเตอร์ในเครื่องที่ปิดอยู่ไม่สามารถทำต่อได้ ความล้มเหลวของเซิร์ฟเวอร์ แรงกดดันด้านหน่วยความจำ และการสูญเสียที่จัดเก็บข้อมูลยังคงต้องมีการกู้คืน ให้เชื่อมต่อใหม่กับ ID งานที่บันทึกไว้และตรวจดูเหตุการณ์ล่าสุดที่ยืนยันแล้วก่อนเริ่มงานเพิ่มเติม อย่าทำคำขอที่มีค่าใช้จ่ายซ้ำโดยไม่พิจารณาในกรณีที่ยังไม่ทราบผลลัพธ์ ดู[การตัดการเชื่อมต่อและการกู้คืน](https://dsh.tvijo.com/knowledge/durable-work-and-recovery)

## ทำให้ค่าใช้จ่ายและข้อมูลมองเห็นได้

ตรวจดูใบเสนอราคาที่ได้รับการยอมรับ เพดานงาน จำนวนเงินที่กันไว้ และใบรับการใช้บริการ ส่วนเพิ่มค่าบริการ 8% จะเปลี่ยนการใช้บริการผู้ให้บริการมูลค่า USD1.00 เป็น USD1.08 ก่อนหักค่าใช้จ่ายอื่นที่แจ้งแยกต่างหาก นี่เป็นเพียงตัวอย่าง ไม่ใช่ข้อเสนอราคา โควตาการสมัครสมาชิก ค่าใช้จ่ายของผู้ให้บริการ และทรัพยากรของเซิร์ฟเวอร์เป็นขีดจำกัดที่แตกต่างกัน การเพิ่มงบประมาณต้องเป็นการเลือกอย่างชัดเจน

ไฟล์ข้อมูลรับรองของ CLI ในเครื่องใช้สิทธิ์แบบเฉพาะเจ้าของเท่านั้น สิทธิ์เหล่านี้ไม่ใช่การเข้ารหัสหรือการสำรองข้อมูล การอัปโหลด Knowledge เป็นการดำเนินการที่ชัดเจน ไฟล์ส่วนตัวไม่ควรเข้าไปอยู่ในลิงก์ส่งต่อแบบสาธารณะ [การส่งต่อพรอมป์ต](https://dsh.tvijo.com/knowledge/prompt-handoffs) อธิบายวิธีคัดลอกงานที่ผ่านการทบทวนไปยังเครื่องมืออื่น

แพ็กเกจของรีโปซิทอรีนี้ปัจจุบันมีเครื่องหมาย `UNLICENSED` การเผยแพร่ไม่ได้ให้สิทธิ์ในการนำไปใช้ซ้ำ ตรวจสอบเมทาดาทาของแพ็กเกจและประกาศเรื่องสัญญาอนุญาตฉบับปัจจุบันก่อนเผยแพร่ต่อ คำแปลเหล่านี้เป็นคู่มือเบื้องต้น สร้างด้วย DSHREM และตรวจสอบความสอดคล้องเชิงโครงสร้าง ฉบับภาษาอังกฤษเป็นแหล่งอ้างอิงเมื่อเกิดความคลาดเคลื่อนทางเทคนิค
