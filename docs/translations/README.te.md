# Tvijo DSHREM — ఒక పని నుండి పరిశీలించిన ఫలితం వరకు

[English](README.en.md) · [Русский](README.ru.md) · [All languages / Все языки](../../README.md#read-the-introductory-guide-in-your-language)

Tvijo ఒక బ్రౌజర్ వర్క్‌స్పేస్, VS Code ఎక్స్‌టెన్షన్ మరియు టెర్మినల్ సాధనాలను ఒక ఉమ్మడి అభివృద్ధి వర్క్‌ఫ్లో చుట్టూ అందిస్తుంది. పనిని వివరించండి, దాని అమలు హోస్ట్ మరియు అనుమతులను ఎంచుకోండి, మార్పులను పరిశీలించండి, మరియు ఫలితాన్ని ఆమోదించడానికి ఉపయోగించిన సాక్ష్యాన్ని ఉంచండి. ఈ గైడ్ ఉత్పత్తిని పరిచయం చేస్తుంది; CLI కు రిపాజిటరీ యొక్క సాంకేతిక README మరియు కమాండ్ రిఫరెన్స్ అధికారికమైనవిగా ఉంటాయి.

## మీకు ఇష్టమైన వర్క్‌స్పేస్‌తో ప్రారంభించండి

[DSHREM](https://dsh.tvijo.com/) తెరవండి, [VS Code ఎక్స్‌టెన్షన్ మరియు టెర్మినల్ సూచనలు](https://dsh.tvijo.com/download) పొందండి, లేదా [సెట్టింగ్స్ వివరణ](https://dsh.tvijo.com/knowledge/settings-explained) చదవండి. సేవ మద్దతు ఇచ్చే ఖాతా ఫ్లో ద్వారా సైన్ ఇన్ చేయండి. ప్రొవైడర్ API కీలను ఎప్పుడూ పంచుకున్న ప్రాంప్ట్‌లో, పబ్లిక్ ఇష్యూలో లేదా రిపాజిటరీలో అతికించవద్దు.

Node.js CLI కు Node 22 లేదా కంటే కొత్తది అవసరం. లోకల్ చెకౌట్ నుండి:

```sh
npm install -g .
dsh login
dsh doctor
dsh chat
```

ఈ కమాండ్ `dshrem`గా కూడా అందుబాటులో ఉంది. ఈ రిమోట్ చాట్ CLI సూచించిన సాధనాలను అమలు చేయకుండా చూపిస్తుంది. లోకల్ ఎడిటింగ్ మరియు కమాండ్ అమలు VS Code Agent లేదా స్పష్టంగా కాన్ఫిగర్ చేసిన హోస్ట్ రన్‌టైమ్‌కు చెందుతాయి; వాటికి వేర్వేరు అనుమతులు ఉంటాయి. [CLI సహాయం](https://github.com/nikbibamon/dshrempub/blob/main/docs/HELP.md) చూడండి.

## ఎంపికలను అర్థం చేసుకోండి

**మొదట సాక్ష్యం** మద్దతు ఉన్న వాస్తవాలను ఊహల నుండి వేరు చేస్తుంది. **ప్లాన్ చేయండి మరియు తనిఖీ చేయండి** ఒక చిన్న ప్లాన్ అడుగుతుంది మరియు ఫలితాన్ని అభ్యర్థనతో పోల్చి తనిఖీ చేస్తుంది. **సమాధానాన్ని సమీక్షించండి** డ్రాఫ్ట్‌ను ప్రశ్నిస్తుంది; వేరు సమీక్షకుడిని స్పష్టంగా నియమించకపోతే అది స్వీయ-సమీక్ష. ఈ పద్ధతుల్లో ఏదీ సరైనతను లేదా తక్కువ టోకెన్ వాడకాన్ని హామీ ఇవ్వదు.

టాస్క్ ప్రీసెట్‌లు పునర్వినియోగించదగిన సూచనలు మరియు తనిఖీ జాబితాలను జోడిస్తాయి. అవి అదనపు మోడల్ మెమరీని సృష్టించవు. పెద్ద కాంటెక్స్ట్ సేకరణ ఇప్పటికీ సేవ మరియు మోడల్ అభ్యర్థన పరిమితుల్లో ఇమిడాలి. అడ్వాన్స్‌డ్ కంట్రోలర్, Python మరియు స్టేట్ పాథ్‌లు ఎంచుకున్న ఎక్స్‌టెన్షన్ హోస్ట్‌ను సూచిస్తాయి; Remote SSH లో అది రిమోట్ సర్వర్.

## సహాయపడినప్పుడు జట్టుతో పని చేయండి

AGENTROY జట్టు కోఆర్డినేటర్, ఇంప్లిమెంటర్లు మరియు సమీక్షకులకు వేర్వేరు బాధ్యతలను కేటాయిస్తుంది. హోస్ట్ పాలసీలు DSHREM ds41f మరియు ఖాతా ఆధారిత Codex లేదా Claude సాధనాలను అభ్యర్థించవచ్చు, ఐచ్ఛిక ఆర్కిటెక్చరల్ సమీక్షతో. లభ్యత ఇన్‌స్టాల్ చేసిన రన్‌టైమ్, ఖాతా యాక్సెస్ మరియు ఎంచుకున్న పాలసీపై ఆధారపడి ఉంటుంది. లేని సబ్‌స్క్రిప్షన్ మౌనంగా చెల్లింపు API కాల్‌గా మారకూడదు.

మూడు నుండి ఆరు పాత్రలు సంస్థాగత ఎంపికలు, నాణ్యత సూత్రం కాదు. సమీక్షకులకు ఖచ్చితమైన ఆర్టిఫాక్ట్ వెర్షన్ మరియు పరీక్ష సాక్ష్యం అవసరం. మోడల్స్ ఏకీభవించినప్పటికీ తీవ్రమైన విఫలమైన తనిఖీ ఆమోదాన్ని నిరోధిస్తుంది. [ఏజెంట్ జట్లు మరియు కనిపించే ఖర్చులు](https://dsh.tvijo.com/knowledge/agentroy-teams-and-costs) చదవండి.

## అనిశ్చితిని దాచకుండా తిరిగి ప్రారంభించండి

డిటాచ్ చేసిన సర్వర్-సైడ్ tmux సెషన్ ల్యాప్‌టాప్ లేదా ఫోన్ డిస్‌కనెక్ట్ అయిన తర్వాత కొనసాగవచ్చు. పవర్ ఆఫ్ చేసిన లోకల్ కంప్యూటర్‌పై పని కొనసాగదు. సర్వర్ వైఫల్యం, మెమరీ ఒత్తిడి మరియు స్టోరేజ్ నష్టానికి ఇప్పటికీ రికవరీ అవసరం. సేవ్ చేసిన టాస్క్ ID కు తిరిగి కనెక్ట్ అయి, మరింత పని ప్రారంభించే ముందు దాని చివరి నిర్ధారిత ఈవెంట్‌ను పరిశీలించండి. ఫలితం తెలియని బిల్ చేయదగిన అభ్యర్థనను గుడ్డిగా పునరావృతం చేయవద్దు. [డిస్‌కనెక్ట్‌లు మరియు రికవరీ](https://dsh.tvijo.com/knowledge/durable-work-and-recovery) చూడండి.

## ఖర్చులు మరియు డేటాను కనిపించేలా ఉంచండి

ఆమోదించిన కోట్, టాస్క్ క్యాప్, రిజర్వ్ చేసిన మొత్తం మరియు వినియోగ రసీదును సమీక్షించండి. 8% సేవ మార్కప్ USD1.00 ప్రొవైడర్ వినియోగాన్ని విడిగా వెల్లడించిన ఛార్జీలకు ముందు USD1.08 గా మారుస్తుంది; ఇది ఒక ఉదాహరణ, ధర ఆఫర్ కాదు. సబ్‌స్క్రిప్షన్ కోటాలు, ప్రొవైడర్ ఛార్జీలు మరియు సర్వర్ వనరులు వేర్వేరు పరిమితులు. అదనపు బడ్జెట్‌కు స్పష్టమైన ఎంపిక అవసరం.

లోకల్ CLI క్రెడెన్షియల్ ఫైళ్లు యజమాని-మాత్రమే అనుమతులను ఉపయోగిస్తాయి. ఈ అనుమతులు ఎన్‌క్రిప్షన్ లేదా బ్యాకప్ కావు. జ్ఞాన అప్‌లోడ్ స్పష్టమైనది; ప్రైవేట్ ఫైళ్లు ఎప్పుడూ పబ్లిక్ హ్యాండాఫ్ లింక్‌లోకి రాకూడదు. [ప్రాంప్ట్ హ్యాండాఫ్‌లు](https://dsh.tvijo.com/knowledge/prompt-handoffs) సమీక్షించిన పనిని మరో సాధనంలోకి కాపీ చేయడాన్ని వివరిస్తాయి.

ఈ రిపాజిటరీ ప్యాకేజీ ప్రస్తుతం `UNLICENSED`గా గుర్తించబడింది; ప్రచురణ పునర్వినియోగ హక్కులను ఇవ్వదు. పునఃపంపిణీ చేయడానికి ముందు ప్రస్తుత ప్యాకేజీ మెటాడేటా మరియు లైసెన్సింగ్ నోటీసును సంప్రదించండి. అనువాదాలు పరిచయ గైడ్‌లు, DSHREM తో రూపొందించబడి నిర్మాణాత్మక స్థిరత్వం కోసం తనిఖీ చేయబడతాయి; సాంకేతిక భేదాలకు ఆంగ్లం ప్రామాణికం.
