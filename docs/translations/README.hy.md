# Tvijo DSHREM — առաջադրանքից մինչև ստուգված արդյունք

[English](README.en.md) · [Русский](README.ru.md) · [All languages / Все языки](../../README.md#read-the-introductory-guide-in-your-language)

Tvijo-ն համախմբում է բրաուզերային աշխատանքային տարածքը, VS Code-ի ընդլայնումը և տերմինալային գործիքները մեկ ընդհանուր ծրագրավորման աշխատընթացի շուրջ։ Նկարագրեք առաջադրանքը, ընտրեք դրա կատարման հոսթը և թույլտվությունները, ստուգեք փոփոխությունները և պահպանեք արդյունքն ընդունելու համար օգտագործված ապացույցները։ Այս ուղեցույցը ներկայացնում է արտադրանքը. պահոցի տեխնիկական README-ն և հրամանների տեղեկատուն մնում են հեղինակավոր CLI-ի համար։

## Սկսեք ձեր նախընտրած աշխատանքային տարածքից

Բացեք [DSHREM](https://dsh.tvijo.com/), ստացեք [VS Code-ի ընդլայնումը և տերմինալի հրահանգները](https://dsh.tvijo.com/download) կամ կարդացեք [կարգավորումների բացատրությունը](https://dsh.tvijo.com/knowledge/settings-explained)։ Մուտք գործեք ծառայության աջակցվող հաշվի միջոցով։ Երբեք մի տեղադրեք մատակարարի API բանալիները ընդհանուր հուշման, հանրային issue-ի կամ պահոցի մեջ։

Node.js CLI-ն պահանջում է Node 22 կամ ավելի նոր տարբերակ։ Տեղական պատճենից՝

```sh
npm install -g .
dsh login
dsh doctor
dsh chat
```

Հրամանը հասանելի է նաև որպես `dshrem`։ Այս հեռավոր չաթային CLI-ն ցուցադրում է առաջարկվող գործիքները՝ առանց դրանք գործարկելու։ Տեղական խմբագրումը և հրամանների կատարումը պատկանում են VS Code Agent-ին կամ հստակ կարգավորված հոսթի runtime-ին. դրանք ունեն առանձին թույլտվություններ։ Տես [CLI-ի օգնությունը](https://github.com/nikbibamon/dshrempub/blob/main/docs/HELP.md)։

## Հասկացեք ընտրանքները

**Ապացույցն առաջին հերթին** տարանջատում է հաստատված փաստերը ենթադրություններից։ **Պլանավորիր և ստուգիր** պահանջում է կարճ պլան և ստուգում է արդյունքը ըստ հարցման։ **Վերանայիր պատասխանը** մարտահրավեր է նետում սևագրին. դա ինքնավերանայում է, եթե առանձին վերանայող հստակ նշանակված չէ։ Այս մեթոդներից ոչ մեկը չի երաշխավորում ճշգրտություն կամ token-ների ավելի ցածր օգտագործում։

Առաջադրանքի նախադրվածները (presets) ավելացնում են վերօգտագործելի հրահանգներ և ստուգաթերթեր։ Դրանք չեն ստեղծում լրացուցիչ մոդելային հիշողություն։ Ավելի մեծ համատեքստի հավաքածուն դեռ պետք է տեղավորվի ծառայության և մոդելի հարցումների սահմանների մեջ։ Ընդլայնված controller-ի, Python-ի և state-ի ուղիները վերաբերում են ընտրված ընդլայնման հոսթին. Remote SSH-ում դա հեռավոր սերվերն է։

## Աշխատեք թիմի հետ, երբ դա օգնում է

AGENTROY թիմը համակարգողին, իրականացնողներին և վերանայողներին վերագրում է տարբեր պատասխանատվություններ։ Հոսթի քաղաքականությունները կարող են պահանջել DSHREM ds41f և հաշվի վրա հիմնված Codex կամ Claude գործիքներ՝ ճարտարապետական վերանայման ընտրովի հնարավորությամբ։ Հասանելիությունը կախված է տեղադրված runtime-ից, հաշվի մուտքից և ընտրված քաղաքականությունից։ Բացակայող բաժանորդագրությունը չպետք է լուռ վերածվի վճարովի API կանչի։

Երեքից վեց դերերը կազմակերպչական ընտրություն են, ոչ թե որակի բանաձև։ Վերանայողներին անհրաժեշտ են արտեֆակտի ճշգրիտ տարբերակը և թեստային ապացույցները։ Լուրջ ձախողված ստուգումը արգելափակում է ընդունումը, նույնիսկ երբ մոդելները համաձայն են։ Կարդացեք [ագենտային թիմերի և տեսանելի ծախսերի մասին](https://dsh.tvijo.com/knowledge/agentroy-teams-and-costs)։

## Վերսկսեք առանց անորոշությունը թաքցնելու

Անջատված սերվերային tmux նստաշրջանը կարող է շարունակվել նոթբուքի կամ հեռախոսի անջատումից հետո։ Անջատված տեղական համակարգչի վրա աշխատանքը չի կարող։ Սերվերի խափանումը, հիշողության ճնշումը և պահուստավորման կորուստը դեռ պահանջում են վերականգնում։ Վերամիացեք պահված առաջադրանքի ID-ին և ստուգեք նրա վերջին հաստատված իրադարձությունը՝ նոր աշխատանք սկսելուց առաջ։ Մի կրկնեք կուրորեն վճարովի հարցում, որի արդյունքն անհայտ է։ Տես [անջատումներ և վերականգնում](https://dsh.tvijo.com/knowledge/durable-work-and-recovery)։

## Պահեք ծախսերն ու տվյալները տեսանելի

Ստուգեք ընդունված գնանշումը, առաջադրանքի սահմանաչափը, ամրագրված գումարը և օգտագործման անդորրագիրը։ 8% սպասարկման հավելավճարը USD1.00 մատակարարի օգտագործումը կվերածի USD1.08-ի՝ առանձին բացահայտված գանձումներից առաջ. սա օրինակ է, ոչ թե գնային առաջարկ։ Բաժանորդագրության քվոտաները, մատակարարի գանձումները և սերվերային ռեսուրսները տարբեր սահմաններ են։ Լրացուցիչ բյուջեն պահանջում է հստակ ընտրություն։

Տեղական CLI-ի հավատարմագրերի ֆայլերը օգտագործում են միայն սեփականատիրոջը հասանելի թույլտվություններ։ Այդ թույլտվությունները ոչ գաղտնագրում են, ոչ պահուստային պատճեն։ Գիտելիքի վերբեռնումը հստակ է. մասնավոր ֆայլերը երբեք չպետք է հայտնվեն հանրային փոխանցման հղումով։ [Prompt-ի փոխանցումները](https://dsh.tvijo.com/knowledge/prompt-handoffs) բացատրում են վերանայված առաջադրանքն այլ գործիքի մեջ պատճենելը։

Այս պահոցի փաթեթը ներկայումս նշված է `UNLICENSED`. հրապարակումը չի տալիս վերօգտագործման իրավունք։ Նախքան վերաբաշխումը ծանոթացեք ընթացիկ փաթեթի մետատվյալներին և լիցենզավորման ծանուցմանը։ Թարգմանությունները ներածական ուղեցույցներ են՝ ստեղծված DSHREM-ով և ստուգված կառուցվածքային համապատասխանության համար. տեխնիկական անհամապատասխանությունների համար հղումը անգլերենն է։
