# Tvijo DSHREM — 작업에서 검증된 결과까지

[English](README.en.md) · [Русский](README.ru.md) · [All languages / Все языки](../../README.md#read-the-introductory-guide-in-your-language)

Tvijo는 브라우저 워크스페이스, VS Code 확장 프로그램, 터미널 도구를 공유 개발 워크플로우 안에서 함께 제공합니다. 작업을 설명하고, 실행 호스트와 권한을 선택하고, 변경 사항을 검토하고, 결과를 승인하는 데 사용한 근거를 보관하십시오. 이 가이드는 제품을 소개합니다. CLI에 대해서는 저장소의 기술 README와 명령 참조가 계속 권위 있는 자료입니다.

## 선호하는 워크스페이스에서 시작하기

[DSHREM](https://dsh.tvijo.com/)을 열거나, [VS Code 확장 프로그램 및 터미널 안내](https://dsh.tvijo.com/download)를 확인하거나, [설정 설명](https://dsh.tvijo.com/knowledge/settings-explained)을 읽어 보십시오. 서비스가 지원하는 계정 흐름을 통해 로그인하십시오. 제공자의 API 키를 공유 프롬프트, 공개 이슈 또는 저장소에 붙여넣지 마십시오.

Node.js CLI는 Node 22 이상이 필요합니다. 로컬 체크아웃에서:

```sh
npm install -g .
dsh login
dsh doctor
dsh chat
```

명령은 `dshrem`으로도 사용할 수 있습니다. 이 원격 채팅 CLI는 제안된 도구를 표시하지만 실행하지는 않습니다. 로컬 편집과 명령 실행은 VS Code Agent 또는 명시적으로 구성된 호스트 런타임에 속하며, 별도의 권한을 가집니다. [CLI 도움말](https://github.com/nikbibamon/dshrempub/blob/main/docs/HELP.md)을 참고하십시오.

## 선택 사항 이해하기

**근거 우선**은 뒷받침되는 사실과 가정을 구분합니다. **계획과 검사**는 짧은 계획을 요청하고 결과를 요청 사항과 대조해 검사합니다. **답변 검토**는 초안에 반론을 제기합니다. 별도의 검토자가 명시적으로 지정되지 않는 한 이는 자기 검토입니다. 이 방법 중 어느 것도 정확성이나 더 적은 토큰 사용을 보장하지 않습니다.

작업 프리셋은 재사용 가능한 지침과 체크리스트를 추가합니다. 작업 프리셋이 추가 모델 메모리를 만들지는 않습니다. 더 큰 컨텍스트 모음도 서비스 및 모델 요청 한도에 맞아야 합니다. 고급 컨트롤러, Python, 상태 경로는 선택된 확장 호스트를 가리키며, Remote SSH에서는 그 호스트가 원격 서버입니다.

## 도움이 될 때는 팀으로 작업하기

AGENTROY 팀은 코디네이터, 구현자, 검토자에게 서로 다른 책임을 배정합니다. 호스트 정책은 DSHREM ds41f와 계정 기반 Codex 또는 Claude 도구를 요청할 수 있으며, 선택적으로 아키텍처 검토를 포함할 수 있습니다. 사용 가능 여부는 설치된 런타임, 계정 접근 권한, 선택한 정책에 따라 달라집니다. 구독이 없을 때 그것이 조용히 유료 API 호출로 바뀌어서는 안 됩니다.

세 개에서 여섯 개의 역할은 조직적 선택이며 품질 공식이 아닙니다. 검토자에게는 정확한 아티팩트 버전과 테스트 근거가 필요합니다. 모델들이 동의하더라도 중대한 실패한 검사는 승인을 막습니다. [에이전트 팀과 가시적 비용](https://dsh.tvijo.com/knowledge/agentroy-teams-and-costs)을 읽어 보십시오.

## 불확실성을 숨기지 않고 재개하기

분리된 서버 측 tmux 세션은 노트북이나 휴대폰 연결이 끊긴 뒤에도 계속될 수 있습니다. 전원이 꺼진 로컬 컴퓨터에서의 작업은 그럴 수 없습니다. 서버 장애, 메모리 압박, 저장소 손실은 여전히 복구가 필요합니다. 저장된 작업 ID로 다시 연결하고 추가 작업을 시작하기 전에 마지막으로 확인된 이벤트를 검토하십시오. 결과를 알 수 없는 과금 청구 요청을 무작정 반복하지 마십시오. [연결 끊김과 복구](https://dsh.tvijo.com/knowledge/durable-work-and-recovery)를 참고하십시오.

## 비용과 데이터를 가시적으로 유지하기

승인된 견적, 작업 상한, 예약 금액, 사용 영수증을 검토하십시오. 8% 서비스 마크업이 적용되면 별도로 공개된 요금 이전에 제공자 사용량 USD1.00이 USD1.08이 됩니다. 이는 예시이며 가격 제안이 아닙니다. 구독 할당량, 제공자 요금, 서버 리소스는 서로 다른 한도입니다. 추가 예산에는 명시적 선택이 필요합니다.

로컬 CLI 자격 증명 파일은 소유자 전용 권한을 사용합니다. 이러한 권한은 암호화나 백업이 아닙니다. 지식 업로드는 명시적이며, 비공개 파일은 공개 인계 링크에 들어가서는 안 됩니다. [프롬프트 인계](https://dsh.tvijo.com/knowledge/prompt-handoffs)는 검토된 작업을 다른 도구로 복사하는 방법을 설명합니다.

이 저장소의 패키지는 현재 `UNLICENSED`로 표시되어 있습니다. 공개해도 재사용 권리가 부여되지 않습니다. 재배포 전에 현재 패키지 메타데이터와 라이선스 고지를 확인하십시오. 번역본은 DSHREM으로 생성되고 구조적 일관성을 검사한 입문 가이드입니다. 기술적 불일치가 있을 경우 영어 원문이 기준입니다.
