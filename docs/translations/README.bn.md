# Tvijo DSHREM — একটি কাজ থেকে যাচাইকৃত ফলাফল পর্যন্ত

[English](README.en.md) · [Русский](README.ru.md) · [All languages / Все языки](../../README.md#read-the-introductory-guide-in-your-language)

Tvijo একটি ব্রাউজার ওয়ার্কস্পেস, একটি VS Code এক্সটেনশন এবং টার্মিনাল টুলগুলোকে একটি সাধারণ ডেভেলপমেন্ট ওয়ার্কফ্লোর চারপাশে একত্র করে। কাজটি বর্ণনা করুন, এর এক্সিকিউশন হোস্ট ও অনুমতিগুলো বাছাই করুন, পরিবর্তনগুলো পরীক্ষা করুন এবং ফলাফল গ্রহণ করার সময় ব্যবহৃত প্রমাণ সংরক্ষণ করুন। এই গাইডটি পণ্যটির পরিচিতি দেয়; CLI-এর জন্য রিপোজিটরির প্রযুক্তিগত README এবং কমান্ড রেফারেন্সই কর্তৃত্বপূর্ণ।

## আপনার পছন্দের ওয়ার্কস্পেস দিয়ে শুরু করুন

[DSHREM](https://dsh.tvijo.com/) খুলুন, [VS Code এক্সটেনশন ও টার্মিনাল নির্দেশনা](https://dsh.tvijo.com/download) পান, অথবা [সেটিংসের ব্যাখ্যা](https://dsh.tvijo.com/knowledge/settings-explained) পড়ুন। পরিষেবার সমর্থিত অ্যাকাউন্ট প্রবাহের মাধ্যমে সাইন ইন করুন। কোনো শেয়ার করা প্রম্পট, পাবলিক ইস্যু বা রিপোজিটরিতে কখনোই প্রোভাইডার API কী পেস্ট করবেন না।

Node.js CLI-এর জন্য Node 22 বা তার পরবর্তী সংস্করণ প্রয়োজন। স্থানীয় চেকআউট থেকে:

```sh
npm install -g .
dsh login
dsh doctor
dsh chat
```

কমান্ডটি `dshrem` নামেও পাওয়া যায়। এই রিমোট চ্যাট CLI প্রস্তাবিত টুলগুলো দেখায় কিন্তু সেগুলো চালায় না। স্থানীয় এডিটিং এবং কমান্ড এক্সিকিউশন VS Code Agent বা স্পষ্টভাবে কনফিগার করা হোস্ট রানটাইমের কাজ; সেগুলোর আলাদা অনুমতি আছে। দেখুন [CLI সহায়তা](https://github.com/nikbibamon/dshrempub/blob/main/docs/HELP.md)।

## পছন্দগুলো বুঝুন

**প্রমাণ আগে** সমর্থিত তথ্যকে অনুমান থেকে আলাদা করে। **পরিকল্পনা ও যাচাই** একটি সংক্ষিপ্ত পরিকল্পনা চায় এবং ফলাফলকে অনুরোধের বিপরীতে যাচাই করে। **উত্তর পুনরীক্ষণ** একটি খসড়াকে চ্যালেঞ্জ করে; এটি স্ব-পুনরীক্ষণ, যদি না আলাদা কোনো পর্যালোচক স্পষ্টভাবে নিযুক্ত থাকে। এই পদ্ধতিগুলোর কোনোটিই সঠিকতা বা কম টোকেন ব্যবহারের নিশ্চয়তা দেয় না।

টাস্ক প্রিসেটগুলো পুনরায় ব্যবহারযোগ্য নির্দেশনা ও চেকলিস্ট যোগ করে। সেগুলো অতিরিক্ত মডেল মেমরি তৈরি করে না। বড় কনটেক্সট সংগ্রহকে এখনও পরিষেবা ও মডেলের অনুরোধ সীমার মধ্যে ফিট হতে হয়। অ্যাডভান্সড কন্ট্রোলার, Python এবং state পাথগুলো নির্বাচিত এক্সটেনশন হোস্টকে নির্দেশ করে; Remote SSH-এ সেটি রিমোট সার্ভার।

## যখন সহায়ক হয় তখন একটি দলের সাথে কাজ করুন

একটি AGENTROY দল একজন কোঅর্ডিনেটর, ইমপ্লিমেন্টার এবং পর্যালোচকদের আলাদা দায়িত্ব দেয়। হোস্ট নীতিগুলো DSHREM ds41f এবং অ্যাকাউন্টভিত্তিক Codex বা Claude টুলের অনুরোধ করতে পারে, সাথে ঐচ্ছিক আর্কিটেকচারাল পর্যালোচনা। প্রাপ্যতা নির্ভর করে ইনস্টল করা রানটাইম, অ্যাকাউন্ট অ্যাক্সেস এবং নির্বাচিত নীতির উপর। অনুপস্থিত সাবস্ক্রিপশন নীরবে একটি পেইড API কল হয়ে উঠতে পারবে না।

তিন থেকে ছয়টি ভূমিকা সাংগঠনিক পছন্দ, মানের কোনো সূত্র নয়। পর্যালোচকদের নির্দিষ্ট আর্টিফ্যাক্ট সংস্করণ এবং পরীক্ষার প্রমাণ প্রয়োজন। গুরুতর ব্যর্থ যাচাই গ্রহণ আটকে দেয়, এমনকি মডেলগুলো একমত হলেও। পড়ুন [এজেন্ট দল ও দৃশ্যমান খরচ](https://dsh.tvijo.com/knowledge/agentroy-teams-and-costs)।

## অনিশ্চয়তা লুকানো ছাড়াই পুনরায় শুরু করুন

একটি ডিট্যাচড সার্ভার-সাইড tmux সেশন ল্যাপটপ বা ফোন সংযোগ বিচ্ছিন্ন হওয়ার পরেও চলতে পারে। বন্ধ থাকা স্থানীয় কম্পিউটারে কাজ চলতে পারে না। সার্ভার ব্যর্থতা, মেমরি চাপ এবং স্টোরেজ ক্ষতির জন্য এখনও পুনরুদ্ধার প্রয়োজন। সংরক্ষিত টাস্ক আইডিতে পুনরায় সংযোগ করুন এবং আরও কাজ শুরু করার আগে এর সর্বশেষ নিশ্চিত ইভেন্ট পরীক্ষা করুন। যে বিলযোগ্য অনুরোধের ফলাফল অজানা, তা অন্ধভাবে পুনরাবৃত্তি করবেন না। দেখুন [সংযোগ বিচ্ছিন্নতা ও পুনরুদ্ধার](https://dsh.tvijo.com/knowledge/durable-work-and-recovery)।

## খরচ ও ডেটা দৃশ্যমান রাখুন

গৃহীত কোট, টাস্ক ক্যাপ, সংরক্ষিত পরিমাণ এবং ব্যবহারের রসিদ পর্যালোচনা করুন। 8% পরিষেবা মার্কআপ আলাদাভাবে ঘোষিত চার্জের আগে USD1.00 প্রোভাইডার ব্যবহারকে USD1.08-এ পরিণত করবে; এটি একটি উদাহরণ, মূল্য প্রস্তাব নয়। সাবস্ক্রিপশন কোটা, প্রোভাইডার চার্জ এবং সার্ভার সম্পদ আলাদা সীমা। অতিরিক্ত বাজেটের জন্য স্পষ্ট পছন্দ প্রয়োজন।

স্থানীয় CLI ক্রেডেনশিয়াল ফাইল শুধুমাত্র মালিকের জন্য অনুমতি ব্যবহার করে। এই অনুমতিগুলো এনক্রিপশন বা ব্যাকআপ নয়। নলেজ আপলোড স্পষ্ট; প্রাইভেট ফাইল কখনোই পাবলিক হ্যান্ডঅফ লিংকে প্রবেশ করা উচিত নয়। [প্রম্পট হ্যান্ডঅফ](https://dsh.tvijo.com/knowledge/prompt-handoffs) ব্যাখ্যা করে কীভাবে একটি পর্যালোচিত কাজ অন্য টুলে কপি করা যায়।

এই রিপোজিটরির প্যাকেজ বর্তমানে `UNLICENSED` হিসেবে চিহ্নিত; প্রকাশনা পুনর্ব্যবহারের অধিকার দেয় না। পুনর্বিতরণের আগে বর্তমান প্যাকেজ মেটাডেটা এবং লাইসেন্সিং নোটিশ দেখুন। অনুবাদগুলো প্রাথমিক গাইড, DSHREM দিয়ে তৈরি এবং কাঠামোগত সামঞ্জস্যের জন্য যাচাইকৃত; প্রযুক্তিগত অসঙ্গতির জন্য ইংরেজি সংস্করণই المرجع (যাচাইকৃত)।
