# Tvijo DSHREM — ਇੱਕ ਟਾਸਕ ਤੋਂ ਜਾਂਚੇ ਹੋਏ ਨਤੀਜੇ ਤੱਕ

[English](README.en.md) · [Русский](README.ru.md) · [All languages / Все языки](../../README.md#read-the-introductory-guide-in-your-language)

Tvijo ਇੱਕ ਸਾਂਝੇ ਵਿਕਾਸ ਵਰਕਫਲੋ ਦੁਆਲੇ ਬ੍ਰਾਊਜ਼ਰ ਵਰਕਸਪੇਸ, VS Code ਐਕਸਟੈਂਸ਼ਨ ਅਤੇ ਟਰਮੀਨਲ ਟੂਲ ਲਿਆਉਂਦਾ ਹੈ। ਕੰਮ ਦਾ ਵਰਣਨ ਕਰੋ, ਉਸ ਦਾ ਐਗਜ਼ੀਕਿਊਸ਼ਨ ਹੋਸਟ ਅਤੇ ਇਜਾਜ਼ਤਾਂ ਚੁਣੋ, ਬਦਲਾਵਾਂ ਦੀ ਜਾਂਚ ਕਰੋ, ਅਤੇ ਨਤੀਜਾ ਸਵੀਕਾਰ ਕਰਨ ਲਈ ਵਰਤੇ ਗਏ ਸਬੂਤ ਸੰਭਾਲ ਕੇ ਰੱਖੋ। ਇਹ ਗਾਈਡ ਉਤਪਾਦ ਦਾ ਪਰੀਚੇ ਦਿੰਦੀ ਹੈ; CLI ਲਈ ਰਿਪੋਜ਼ਟਰੀ ਦਾ ਤਕਨੀਕੀ README ਅਤੇ ਕਮਾਂਡ ਰੈਫਰੈਂਸ ਹੀ ਅਧਿਕਾਰਤ ਰਹਿੰਦੇ ਹਨ।

## ਆਪਣੇ ਪਸੰਦੀਦਾ ਵਰਕਸਪੇਸ ਨਾਲ ਸ਼ੁਰੂ ਕਰੋ

[DSHREM](https://dsh.tvijo.com/) ਖੋਲ੍ਹੋ, [VS Code ਐਕਸਟੈਂਸ਼ਨ ਅਤੇ ਟਰਮੀਨਲ ਹਦਾਇਤਾਂ](https://dsh.tvijo.com/download) ਲਵੋ, ਜਾਂ [ਸੈਟਿੰਗਾਂ ਦੀ ਵਿਆਖਿਆ](https://dsh.tvijo.com/knowledge/settings-explained) ਪੜ੍ਹੋ। ਸੇਵਾ ਦੇ ਸਮਰਥਿਤ ਅਕਾਊਂਟ ਫਲੋ ਰਾਹੀਂ ਸਾਈਨ ਇਨ ਕਰੋ। ਪ੍ਰੋਵਾਈਡਰ API ਕੁੰਜੀਆਂ ਕਦੇ ਵੀ ਸਾਂਝੇ ਪ੍ਰੌਂਪਟ, ਜਨਤਕ ਇਸ਼ੂ ਜਾਂ ਰਿਪੋਜ਼ਟਰੀ ਵਿੱਚ ਨਾ ਪਾਓ।

Node.js CLI ਲਈ Node 22 ਜਾਂ ਨਵੇਂ ਸੰਸਕਰਣ ਦੀ ਲੋੜ ਹੈ। ਲੋਕਲ ਚੈੱਕਆਊਟ ਤੋਂ:

```sh
npm install -g .
dsh login
dsh doctor
dsh chat
```

ਇਹ ਕਮਾਂਡ `dshrem` ਦੇ ਨਾਂ ਨਾਲ ਵੀ ਉਪਲਬਧ ਹੈ। ਇਹ ਰਿਮੋਟ ਚੈਟ CLI ਸੁਝਾਏ ਗਏ ਟੂਲ ਦਿਖਾਉਂਦੀ ਹੈ ਪਰ ਉਹਨਾਂ ਨੂੰ ਚਲਾਉਂਦੀ ਨਹੀਂ। ਲੋਕਲ ਐਡਿਟਿੰਗ ਅਤੇ ਕਮਾਂਡ ਐਗਜ਼ੀਕਿਊਸ਼ਨ VS Code Agent ਜਾਂ ਸਪਸ਼ਟ ਤੌਰ ਤੇ ਕਨਫਿਗਰ ਕੀਤੇ ਹੋਸਟ ਰਨਟਾਈਮ ਦਾ ਹਿੱਸਾ ਹਨ; ਉਹਨਾਂ ਦੀਆਂ ਇਜਾਜ਼ਤਾਂ ਵੱਖਰੀਆਂ ਹਨ। [CLI ਮਦਦ](https://github.com/nikbibamon/dshrempub/blob/main/docs/HELP.md) ਦੇਖੋ।

## ਚੋਣਾਂ ਨੂੰ ਸਮਝੋ

**ਸਬੂਤ ਪਹਿਲਾਂ** ਸਮਰਥਿਤ ਤੱਥਾਂ ਨੂੰ ਧਾਰਨਾਵਾਂ ਤੋਂ ਵੱਖ ਕਰਦਾ ਹੈ। **ਯੋਜਨਾ ਅਤੇ ਜਾਂਚ** ਇੱਕ ਛੋਟੀ ਯੋਜਨਾ ਮੰਗਦਾ ਹੈ ਅਤੇ ਨਤੀਜੇ ਨੂੰ ਬੇਨਤੀ ਦੇ ਵਿਰੁੱਧ ਜਾਂਚਦਾ ਹੈ। **ਜਵਾਬ ਦੀ ਸਮੀਖਿਆ** ਡਰਾਫਟ ਨੂੰ ਚੁਣੌਤੀ ਦਿੰਦੀ ਹੈ; ਜਦੋਂ ਤੱਕ ਕੋਈ ਵੱਖਰਾ ਸਮੀਖਿਅਕ ਸਪਸ਼ਟ ਤੌਰ ਤੇ ਨਹੀਂ ਦਿੱਤਾ ਜਾਂਦਾ, ਇਹ ਸਵੈ-ਸਮੀਖਿਆ ਹੁੰਦੀ ਹੈ। ਇਹਨਾਂ ਵਿੱਚੋਂ ਕੋਈ ਵੀ ਢੰਗ ਸ਼ੁੱਧਤਾ ਜਾਂ ਘੱਟ ਟੋਕਨ ਵਰਤੋਂ ਦੀ ਗਾਰੰਟੀ ਨਹੀਂ ਦਿੰਦਾ।

ਟਾਸਕ ਪ੍ਰੀਸੈੱਟ ਦੁਬਾਰਾ ਵਰਤੋਂ ਯੋਗ ਹਦਾਇਤਾਂ ਅਤੇ ਚੈੱਕਲਿਸਟ ਜੋੜਦੇ ਹਨ। ਉਹ ਵਾਧੂ ਮਾਡਲ ਮੈਮੋਰੀ ਨਹੀਂ ਬਣਾਉਂਦੇ। ਵੱਡਾ ਕਾਂਟੈਕਸਟ ਸੰਗ੍ਰਹਿ ਵੀ ਸੇਵਾ ਅਤੇ ਮਾਡਲ ਦੀਆਂ ਬੇਨਤੀ ਸੀਮਾਵਾਂ ਵਿੱਚ ਫਿੱਟ ਹੋਣਾ ਲਾਜ਼ਮੀ ਹੈ। ਐਡਵਾਂਸਡ ਕੰਟਰੋਲਰ, Python ਅਤੇ ਸਟੇਟ ਪਾਥ ਚੁਣੇ ਗਏ ਐਕਸਟੈਂਸ਼ਨ ਹੋਸਟ ਨੂੰ ਦਰਸਾਉਂਦੇ ਹਨ; Remote SSH ਵਿੱਚ ਉਹ ਰਿਮੋਟ ਸਰਵਰ ਹੁੰਦਾ ਹੈ।

## ਜਦੋਂ ਲਾਭਦਾਇਕ ਹੋਵੇ ਤਾਂ ਟੀਮ ਨਾਲ ਕੰਮ ਕਰੋ

AGENTROY ਟੀਮ ਇੱਕ ਕੋਆਰਡੀਨੇਟਰ, ਇੰਪਲੀਮੈਂਟਰਾਂ ਅਤੇ ਸਮੀਖਿਅਕਾਂ ਨੂੰ ਵੱਖਰੀਆਂ ਜ਼ਿੰਮੇਵਾਰੀਆਂ ਦਿੰਦੀ ਹੈ। ਹੋਸਟ ਨੀਤੀਆਂ DSHREM ds41f ਅਤੇ ਅਕਾਊਂਟ-ਅਧਾਰਿਤ Codex ਜਾਂ Claude ਟੂਲਾਂ ਦੀ ਬੇਨਤੀ ਕਰ ਸਕਦੀਆਂ ਹਨ, ਜਿਸ ਵਿੱਚ ਵਿਕਲਪਿਕ ਆਰਕੀਟੈਕਚਰਲ ਸਮੀਖਿਆ ਵੀ ਸ਼ਾਮਲ ਹੈ। ਉਪਲਬਧਤਾ ਸਥਾਪਿਤ ਰਨਟਾਈਮ, ਅਕਾਊਂਟ ਪਹੁੰਚ ਅਤੇ ਚੁਣੀ ਗਈ ਨੀਤੀ ਤੇ ਨਿਰਭਰ ਕਰਦੀ ਹੈ। ਗੁੰਮ ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਚੁੱਪਚਾਪ ਭੁਗਤਾਨ ਵਾਲੀ API ਕਾਲ ਨਹੀਂ ਬਣਨੀ ਚਾਹੀਦੀ।

ਤਿੰਨ ਤੋਂ ਛੇ ਭੂਮਿਕਾਵਾਂ ਸੰਸਥਾ ਦੀਆਂ ਚੋਣਾਂ ਹਨ, ਗੁਣਵੱਤਾ ਦਾ ਕੋਈ ਫਾਰਮੂਲਾ ਨਹੀਂ। ਸਮੀਖਿਅਕਾਂ ਨੂੰ ਸਹੀ ਆਰਟੀਫੈਕਟ ਸੰਸਕਰਣ ਅਤੇ ਟੈਸਟ ਸਬੂਤ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ। ਗੰਭੀਰ ਅਸਫਲ ਜਾਂਚ ਸਵੀਕ੍ਰਿਤੀ ਨੂੰ ਰੋਕਦੀ ਹੈ, ਭਾਵੇਂ ਮਾਡਲ ਸਹਿਮਤ ਹੋਣ। [ਏਜੰਟ ਟੀਮਾਂ ਅਤੇ ਦਿਖਣ ਵਾਲੀਆਂ ਲਾਗਤਾਂ](https://dsh.tvijo.com/knowledge/agentroy-teams-and-costs) ਪੜ੍ਹੋ।

## ਅਨਿਸ਼ਚਿਤਤਾ ਲੁਕਾਏ ਬਿਨਾਂ ਮੁੜ ਸ਼ੁਰੂ ਕਰੋ

ਡਿਟੈਚ ਕੀਤਾ ਸਰਵਰ-ਸਾਈਡ tmux ਸੈਸ਼ਨ ਲੈਪਟਾਪ ਜਾਂ ਫ਼ੋਨ ਦੇ ਡਿਸਕਨੈਕਟ ਹੋਣ ਤੋਂ ਬਾਅਦ ਵੀ ਜਾਰੀ ਰਹਿ ਸਕਦਾ ਹੈ। ਬੰਦ ਪਏ ਲੋਕਲ ਕੰਪਿਊਟਰ ਤੇ ਕੰਮ ਨਹੀਂ ਚੱਲ ਸਕਦਾ। ਸਰਵਰ ਫੇਲ੍ਹ ਹੋਣ, ਮੈਮੋਰੀ ਦਬਾਅ ਅਤੇ ਸਟੋਰੇਜ ਖੋਣ ਲਈ ਫਿਰ ਵੀ ਰਿਕਵਰੀ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ। ਹੋਰ ਕੰਮ ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਸੰਭਾਲੇ ਹੋਏ ਟਾਸਕ ID ਨਾਲ ਦੁਬਾਰਾ ਜੁੜੋ ਅਤੇ ਉਸ ਦੀ ਆਖਰੀ ਪੁਸ਼ਟੀ ਕੀਤੀ ਘਟਨਾ ਦੀ ਜਾਂਚ ਕਰੋ। ਜਿਸ ਭੁਗਤਾਨ ਯੋਗ ਬੇਨਤੀ ਦਾ ਨਤੀਜਾ ਅਣਜਾਣ ਹੈ, ਉਸਨੂੰ ਅੰਨ੍ਹੇਵਾਹ ਦੁਹਰਾਓ ਨਾ। [ਡਿਸਕਨੈਕਟ ਅਤੇ ਰਿਕਵਰੀ](https://dsh.tvijo.com/knowledge/durable-work-and-recovery) ਦੇਖੋ।

## ਲਾਗਤਾਂ ਅਤੇ ਡੇਟਾ ਦਿਖਣਯੋਗ ਰੱਖੋ

ਸਵੀਕਾਰ ਕੀਤਾ ਕੋਟ, ਟਾਸਕ ਕੈਪ, ਰਾਖਵੀਂ ਰਕਮ ਅਤੇ ਵਰਤੋਂ ਦੀ ਰਸੀਦ ਦੀ ਸਮੀਖਿਆ ਕਰੋ। 8% ਸੇਵਾ ਮਾਰਕਅੱਪ USD1.00 ਪ੍ਰੋਵਾਈਡਰ ਵਰਤੋਂ ਨੂੰ ਵੱਖਰੇ ਤੌਰ ਤੇ ਦੱਸੇ ਗਏ ਖਰਚਿਆਂ ਤੋਂ ਪਹਿਲਾਂ USD1.08 ਬਣਾ ਦੇਵੇਗਾ; ਇਹ ਇੱਕ ਉਦਾਹਰਨ ਹੈ, ਕੀਮਤ ਦੀ ਪੇਸ਼ਕਸ਼ ਨਹੀਂ। ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਕੋਟਾ, ਪ੍ਰੋਵਾਈਡਰ ਖਰਚੇ ਅਤੇ ਸਰਵਰ ਸਰੋਤ ਵੱਖਰੀਆਂ ਸੀਮਾਵਾਂ ਹਨ। ਵਾਧੂ ਬਜਟ ਲਈ ਸਪਸ਼ਟ ਚੋਣ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ।

ਲੋਕਲ CLI ਕ੍ਰੈਡੈਂਸ਼ਲ ਫਾਈਲਾਂ ਸਿਰਫ਼ ਮਾਲਕ ਲਈ ਇਜਾਜ਼ਤਾਂ ਵਰਤਦੀਆਂ ਹਨ। ਇਹ ਇਜਾਜ਼ਤਾਂ ਐਨਕ੍ਰਿਪਸ਼ਨ ਜਾਂ ਬੈਕਅੱਪ ਨਹੀਂ ਹਨ। ਨਾਲੇਜ ਅੱਪਲੋਡ ਸਪਸ਼ਟ ਹੁੰਦਾ ਹੈ; ਪ੍ਰਾਈਵੇਟ ਫਾਈਲਾਂ ਕਦੇ ਵੀ ਜਨਤਕ ਹੈਂਡਆਫ ਲਿੰਕ ਵਿੱਚ ਨਹੀਂ ਜਾਣੀਆਂ ਚਾਹੀਦੀਆਂ। [ਪ੍ਰੌਂਪਟ ਹੈਂਡਆਫ](https://dsh.tvijo.com/knowledge/prompt-handoffs) ਦੱਸਦਾ ਹੈ ਕਿ ਸਮੀਖਿਆ ਕੀਤੇ ਟਾਸਕ ਨੂੰ ਕਿਸੇ ਹੋਰ ਟੂਲ ਵਿੱਚ ਕਿਵੇਂ ਕਾਪੀ ਕਰਨਾ ਹੈ।

ਇਸ ਰਿਪੋਜ਼ਟਰੀ ਦਾ ਪੈਕੇਜ ਇਸ ਸਮੇਂ `UNLICENSED` ਵਜੋਂ ਨਿਸ਼ਾਨਿਤ ਹੈ; ਪ੍ਰਕਾਸ਼ਨ ਮੁੜ ਵਰਤੋਂ ਦੇ ਹੱਕ ਨਹੀਂ ਦਿੰਦਾ। ਮੁੜ ਵੰਡਣ ਤੋਂ ਪਹਿਲਾਂ ਮੌਜੂਦਾ ਪੈਕੇਜ ਮੈਟਾਡੇਟਾ ਅਤੇ ਲਾਇਸੈਂਸ ਨੋਟਿਸ ਦੇਖੋ। ਅਨੁਵਾਦ ਸ਼ੁਰੂਆਤੀ ਗਾਈਡ ਹਨ, ਜੋ DSHREM ਨਾਲ ਤਿਆਰ ਕੀਤੇ ਗਏ ਅਤੇ ਸੰਰਚਨਾਤਮਕ ਇਕਸਾਰਤਾ ਲਈ ਜਾਂਚੇ ਗਏ ਹਨ; ਤਕਨੀਕੀ ਅੰਤਰਾਂ ਲਈ ਅੰਗਰੇਜ਼ੀ ਹੀ ਸੰਦਰਭ ਹੈ।
