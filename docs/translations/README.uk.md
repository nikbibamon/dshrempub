# Tvijo DSHREM — від завдання до перевіреного результату

[English](README.en.md) · [Русский](README.ru.md) · [All languages / Все языки](../../README.md#read-the-introductory-guide-in-your-language)

Tvijo об'єднує браузерний робочий простір, розширення VS Code та термінальні інструменти навколо спільного робочого процесу розробки. Опишіть завдання, виберіть хост виконання та дозволи, перегляньте зміни й збережіть свідчення, використані для приймання результату. Цей посібник є вступом до продукту; технічний README репозиторію та довідник команд залишаються авторитетними для CLI.

## Почніть із бажаного робочого простору

Відкрийте [DSHREM](https://dsh.tvijo.com/), отримайте [розширення VS Code та інструкції для термінала](https://dsh.tvijo.com/download) або прочитайте [пояснення налаштувань](https://dsh.tvijo.com/knowledge/settings-explained). Увійдіть через підтримуваний сервісом потік входу в обліковий запис. Ніколи не вставляйте API-ключі провайдерів у спільний запит, публічну issue або репозиторій.

CLI для Node.js потребує Node 22 або новішої версії. Із локальної копії репозиторію:

```sh
npm install -g .
dsh login
dsh doctor
dsh chat
```

Команда також доступна як `dshrem`. Цей віддалений CLI чату показує запропоновані інструменти, не виконуючи їх. Локальне редагування та виконання команд належать до VS Code Agent або явно налаштованого хост-середовища виконання; вони мають окремі дозволи. Див. [довідку CLI](https://github.com/nikbibamon/dshrempub/blob/main/docs/HELP.md).

## Розберіться у варіантах

**Спочатку свідчення** відокремлює підтверджені факти від припущень. **Плануй і перевіряй** вимагає короткого плану й зіставляє результат із запитом. **Переглянь відповідь** оскаржує чернетку; це самоперевірка, якщо окремо не призначено іншого рецензента. Жоден із цих методів не гарантує правильності чи меншого споживання токенів.

Пресети завдань додають повторно використовувані інструкції та контрольні списки. Вони не створюють додаткової пам'яті моделі. Більший набір контексту все одно має вкладатися в ліміти запиту сервісу та моделі. Шляхи advanced controller, Python і state стосуються вибраного хоста розширення; у Remote SSH це віддалений сервер.

## Працюйте в команді, коли це доречно

Команда AGENTROY призначає координатору, виконавцям і рецензентам різні обов'язки. Політики хоста можуть запитувати DSHREM ds41f та інструменти Codex або Claude на основі облікового запису з необов'язковим архітектурним рецензуванням. Доступність залежить від встановленого середовища виконання, доступу до облікового запису та вибраної політики. Відсутня підписка не повинна мовчки перетворюватися на платний виклик API.

Три–шість ролей — це організаційний вибір, а не формула якості. Рецензентам потрібна точна версія артефакту та свідчення тестів. Серйозна невдала перевірка блокує приймання, навіть коли моделі погоджуються. Прочитайте [команди агентів і видимі витрати](https://dsh.tvijo.com/knowledge/agentroy-teams-and-costs).

## Продовжуйте, не приховуючи невизначеності

Відокремлена серверна сесія tmux може продовжуватися після від'єднання ноутбука чи телефона. Робота на вимкненому локальному комп'ютері — ні. Збій сервера, нестача пам'яті та втрата сховища все одно потребують відновлення. Перепідключіться до збереженого ідентифікатора завдання й перегляньте його останню підтверджену подію, перш ніж починати подальшу роботу. Не повторюйте наосліп платний запит, результат якого невідомий. Див. [від'єднання та відновлення](https://dsh.tvijo.com/knowledge/durable-work-and-recovery).

## Тримайте витрати й дані видимими

Перегляньте прийняту пропозицію, ліміт завдання, зарезервовану суму та квитанцію про використання. 8% сервісна націнка перетворила б USD1.00 використання провайдера на USD1.08 до окремо зазначених нарахувань; це приклад, а не цінова пропозиція. Квоти підписок, нарахування провайдерів і серверні ресурси — це різні ліміти. Додатковий бюджет потребує явного вибору.

Локальні файли облікових даних CLI мають дозволи лише для власника. Ці дозволи не є шифруванням чи резервною копією. Завантаження знань є явним; приватні файли ніколи не повинні потрапляти в публічне посилання для передавання. [Передавання запитів](https://dsh.tvijo.com/knowledge/prompt-handoffs) пояснює копіювання перевіреного завдання в інший інструмент.

Пакет цього репозиторію наразі позначено як `UNLICENSED`; публікація не надає прав на повторне використання. Перед розповсюдженням звіртеся з поточними метаданими пакета та повідомленням про ліцензування. Переклади є вступними посібниками, згенерованими за допомогою DSHREM і перевіреними на структурну узгодженість; англійська версія є еталоном у разі технічних розбіжностей.
