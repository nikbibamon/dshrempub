# Tvijo DSHREM — ഒരു ടാസ്കിൽ നിന്ന് പരിശോധിച്ച ഫലത്തിലേക്ക്

[English](README.en.md) · [Русский](README.ru.md) · [All languages / Все языки](../../README.md#read-the-introductory-guide-in-your-language)

Tvijo ഒരു പങ്കിട്ട ഡെവലപ്‌മെന്റ് വർക്ക്ഫ്ലോയ്ക്ക് ചുറ്റും ഒരു ബ്രൗസർ വർക്ക്സ്പേസ്, ഒരു VS Code എക്സ്റ്റൻഷൻ, ടെർമിനൽ ടൂളുകൾ എന്നിവ കൊണ്ടുവരുന്നു. ടാസ്ക് വിവരിക്കുക, അതിന്റെ എക്സിക്യൂഷൻ ഹോസ്റ്റും അനുമതികളും തിരഞ്ഞെടുക്കുക, മാറ്റങ്ങൾ പരിശോധിക്കുക, ഫലം സ്വീകരിക്കാൻ ഉപയോഗിച്ച തെളിവുകൾ സൂക്ഷിക്കുക. ഈ ഗൈഡ് ഉൽപ്പന്നം പരിചയപ്പെടുത്തുന്നു; CLI-ക്ക് റിപ്പോസിറ്ററിയുടെ സാങ്കേതിക README-യും കമാൻഡ് റഫറൻസും തന്നെയാണ് അധികാരപരമായ ഉറവിടം.

## നിങ്ങൾക്ക് ഇഷ്ടമുള്ള വർക്ക്സ്പേസിൽ തുടങ്ങുക

[DSHREM](https://dsh.tvijo.com/) തുറക്കുക, [VS Code എക്സ്റ്റൻഷനും ടെർമിനൽ നിർദ്ദേശങ്ങളും](https://dsh.tvijo.com/download) നേടുക, അല്ലെങ്കിൽ [സെറ്റിംഗ്സ് വിശദീകരിച്ചത്](https://dsh.tvijo.com/knowledge/settings-explained) വായിക്കുക. സേവനം പിന്തുണയ്ക്കുന്ന അക്കൗണ്ട് ഫ്ലോ വഴി സൈൻ ഇൻ ചെയ്യുക. പ്രൊവൈഡർ API കീകൾ ഒരിക്കലും പങ്കിട്ട പ്രോംപ്റ്റിലും പൊതു ഇഷ്യൂവിലും റിപ്പോസിറ്ററിയിലും ഒട്ടിക്കരുത്.

Node.js CLI-ക്ക് Node 22 അല്ലെങ്കിൽ അതിൽ പുതിയത് ആവശ്യമാണ്. ഒരു ലോക്കൽ ചെക്ക്ഔട്ടിൽ നിന്ന്:

```sh
npm install -g .
dsh login
dsh doctor
dsh chat
```

ഈ കമാൻഡ് `dshrem` എന്ന പേരിലും ലഭ്യമാണ്. ഈ റിമോട്ട് ചാറ്റ് CLI നിർദ്ദേശിച്ച ടൂളുകൾ പ്രദർശിപ്പിക്കുന്നു, അവ എക്സിക്യൂട്ട് ചെയ്യുന്നില്ല. ലോക്കൽ എഡിറ്റിംഗും കമാൻഡ് എക്സിക്യൂഷനും VS Code Agent-ന്റതോ വ്യക്തമായി കോൺഫിഗർ ചെയ്ത ഹോസ്റ്റ് റൺടൈമിന്റതോ ആണ്; അവയ്ക്ക് വെവ്വേറെ അനുമതികളുണ്ട്. [CLI സഹായം](https://github.com/nikbibamon/dshrempub/blob/main/docs/HELP.md) കാണുക.

## തിരഞ്ഞെടുപ്പുകൾ മനസ്സിലാക്കുക

**തെളിവ് ആദ്യം** പിന്തുണയുള്ള വസ്തുതകളെ അനുമാനങ്ങളിൽ നിന്ന് വേർതിരിക്കുന്നു. **പ്ലാൻ ചെയ്ത് പരിശോധിക്കുക** ഒരു ചെറിയ പ്ലാൻ ആവശ്യപ്പെടുകയും ഫലം അഭ്യർത്ഥനയുമായി ഒത്തുനോക്കുകയും ചെയ്യുന്നു. **ഉത്തരം അവലോകനം ചെയ്യുക** ഒരു ഡ്രാഫ്റ്റിനെ വെല്ലുവിളിക്കുന്നു; പ്രത്യേകം ഒരു റിവ്യൂവർ വ്യക്തമായി നിയോഗിക്കപ്പെട്ടില്ലെങ്കിൽ ഇത് സ്വയം-അവലോകനമാണ്. ഈ രീതികളൊന്നും കൃത്യതയോ കുറഞ്ഞ ടോക്കൺ ഉപയോഗമോ ഉറപ്പുനൽകുന്നില്ല.

ടാസ്ക് പ്രീസെറ്റുകൾ പുനരുപയോഗിക്കാവുന്ന നിർദ്ദേശങ്ങളും ചെക്ക്ലിസ്റ്റുകളും ചേർക്കുന്നു. അവ അധിക മോഡൽ മെമ്മറി സൃഷ്ടിക്കുന്നില്ല. വലിയ ഒരു കോൺടെക്സ്റ്റ് ശേഖരം ഇപ്പോഴും സേവനത്തിന്റെയും മോഡൽ അഭ്യർത്ഥനയുടെയും പരിധികൾക്കുള്ളിൽ ഒതുങ്ങണം. അഡ്‌വാൻസ്ഡ് കൺട്രോളർ, Python, സ്റ്റേറ്റ് പാതകൾ എന്നിവ തിരഞ്ഞെടുത്ത എക്സ്റ്റൻഷൻ ഹോസ്റ്റിനെ സൂചിപ്പിക്കുന്നു; Remote SSH-ൽ അത് റിമോട്ട് സർവറാണ്.

## സഹായകരമാകുമ്പോൾ ഒരു ടീമിനൊപ്പം പ്രവർത്തിക്കുക

ഒരു AGENTROY ടീം ഒരു കോർഡിനേറ്ററിനും നടപ്പാക്കുന്നവർക്കും റിവ്യൂവർമാർക്കും വ്യത്യസ്ത ഉത്തരവാദിത്തങ്ങൾ നൽകുന്നു. ഹോസ്റ്റ് പോളിസികൾ DSHREM ds41f-ഉം അക്കൗണ്ട് അടിസ്ഥാനമാക്കിയ Codex അല്ലെങ്കിൽ Claude ടൂളുകളും അഭ്യർത്ഥിച്ചേക്കാം, ഓപ്ഷണൽ ആർക്കിടെക്ചറൽ അവലോകനത്തോടെ. ഇൻസ്റ്റാൾ ചെയ്ത റൺടൈം, അക്കൗണ്ട് ആക്സസ്, തിരഞ്ഞെടുത്ത പോളിസി എന്നിവയെ ആശ്രയിച്ചിരിക്കും ലഭ്യത. ഇല്ലാത്ത ഒരു സബ്‌സ്ക്രിപ്ഷൻ നിശബ്ദമായി ഒരു പെയ്ഡ് API കോളായി മാറരുത്.

മൂന്ന് മുതൽ ആറ് വരെ റോളുകൾ ഓർഗനൈസേഷൻ തിരഞ്ഞെടുപ്പുകളാണ്, ഒരു ഗുണനിലവാര സൂത്രവാക്യമല്ല. റിവ്യൂവർമാർക്ക് കൃത്യമായ ആർട്ടിഫാക്ട് പതിപ്പും ടെസ്റ്റ് തെളിവും ആവശ്യമാണ്. മോഡലുകൾ യോജിക്കുമ്പോഴും ഗുരുതരമായി പരാജയപ്പെട്ട ഒരു ചെക്ക് സ്വീകാര്യത തടയുന്നു. [ഏജന്റ് ടീമുകളും ദൃശ്യമായ ചെലവുകളും](https://dsh.tvijo.com/knowledge/agentroy-teams-and-costs) വായിക്കുക.

## അനിശ്ചിതത്വം മറയ്ക്കാതെ തുടരുക

ഒരു ഡിറ്റാച്ച്ഡ് സർവർ-സൈഡ് tmux സെഷൻ ലാപ്‌ടോപ്പോ ഫോണോ ഡിസ്കണക്ട് ചെയ്തതിന് ശേഷവും തുടരാം. പവർ ഓഫ് ചെയ്ത ലോക്കൽ കമ്പ്യൂട്ടറിലെ ജോലി തുടരാനാകില്ല. സർവർ പരാജയം, മെമ്മറി സമ്മർദ്ദം, സ്റ്റോറേജ് നഷ്ടം എന്നിവയ്ക്ക് ഇപ്പോഴും റിക്കവറി ആവശ്യമാണ്. സേവ് ചെയ്ത ടാസ്ക് ID-യിലേക്ക് വീണ്ടും കണക്ട് ചെയ്ത്, കൂടുതൽ ജോലി തുടങ്ങുന്നതിന് മുമ്പ് അതിന്റെ അവസാനം സ്ഥിരീകരിച്ച ഇവന്റ് പരിശോധിക്കുക. ഫലം അജ്ഞാതമായ ഒരു ബില്ലബിൾ അഭ്യർത്ഥന അന്ധമായി ആവർത്തിക്കരുത്. [ഡിസ്കണക്ടുകളും റിക്കവറിയും](https://dsh.tvijo.com/knowledge/durable-work-and-recovery) കാണുക.

## ചെലവുകളും ഡാറ്റയും ദൃശ്യമായി സൂക്ഷിക്കുക

സ്വീകരിച്ച ക്വോട്ട്, ടാസ്ക് പരിധി, റിസർവ് ചെയ്ത തുക, ഉപയോഗ രസീത് എന്നിവ പരിശോധിക്കുക. 8% സേവന മാർജിൻ USD1.00 പ്രൊവൈഡർ ഉപയോഗത്തെ പ്രത്യേകം വെളിപ്പെടുത്തിയ ചാർജുകൾക്ക് മുമ്പ് USD1.08 ആക്കി മാറ്റും; ഇത് ഒരു ഉദാഹരണമാണ്, വില വാഗ്ദാനമല്ല. സബ്‌സ്ക്രിപ്ഷൻ ക്വോട്ടകൾ, പ്രൊവൈഡർ ചാർജുകൾ, സർവർ റിസോഴ്‌സുകൾ എന്നിവ വ്യത്യസ്ത പരിധികളാണ്. അധിക ബജറ്റിന് വ്യക്തമായ ഒരു തിരഞ്ഞെടുപ്പ് ആവശ്യമാണ്.

ലോക്കൽ CLI ക്രെഡൻഷ്യൽ ഫയലുകൾ ഉടമയ്ക്ക് മാത്രമുള്ള അനുമതികൾ ഉപയോഗിക്കുന്നു. ഈ അനുമതികൾ എൻക്രിപ്ഷനോ ബാക്കപ്പോ അല്ല. നോളജ് അപ്‌ലോഡ് വ്യക്തമാണ്; സ്വകാര്യ ഫയലുകൾ ഒരിക്കലും ഒരു പൊതു ഹാൻഡ്ഓഫ് ലിങ്കിൽ പ്രവേശിക്കരുത്. അവലോകനം ചെയ്ത ഒരു ടാസ്ക് മറ്റൊരു ടൂളിലേക്ക് പകർത്തുന്നത് [പ്രോംപ്റ്റ് ഹാൻഡ്ഓഫുകൾ](https://dsh.tvijo.com/knowledge/prompt-handoffs) വിശദീകരിക്കുന്നു.

ഈ റിപ്പോസിറ്ററിയുടെ പാക്കേജ് ഇപ്പോൾ `UNLICENSED` എന്ന് അടയാളപ്പെടുത്തിയിരിക്കുന്നു; പ്രസിദ്ധീകരണം പുനരുപയോഗാവകാശങ്ങൾ നൽകുന്നില്ല. പുനർവിതരണത്തിന് മുമ്പ് നിലവിലെ പാക്കേജ് മെറ്റാഡാറ്റയും ലൈസൻസിംഗ് അറിയിപ്പും പരിശോധിക്കുക. വിവർത്തനങ്ങൾ DSHREM ഉപയോഗിച്ച് സൃഷ്ടിച്ച് ഘടനാപരമായ സ്ഥിരതയ്ക്കായി പരിശോധിച്ച ആമുഖ ഗൈഡുകളാണ്; സാങ്കേതിക വ്യത്യാസങ്ങൾക്ക് ഇംഗ്ലീഷാണ് പരാമർശം.
