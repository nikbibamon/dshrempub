# Tvijo DSHREM — ஒரு பணியிலிருந்து சரிபார்க்கப்பட்ட முடிவு வரை

[English](README.en.md) · [Русский](README.ru.md) · [All languages / Все языки](../../README.md#read-the-introductory-guide-in-your-language)

Tvijo ஒரு பகிரப்பட்ட மேம்பாட்டு பணிப்பாய்வைச் சுற்றி ஒரு உலாவி பணியிடத்தையும், VS Code நீட்டிப்பையும், முனையக் கருவிகளையும் இணைக்கிறது. பணியை விவரிக்கவும், அதன் இயக்கத் தங்குமிடத்தையும் அனுமதிகளையும் தேர்ந்தெடுக்கவும், மாற்றங்களைப் பரிசீலிக்கவும், முடிவை ஏற்கப் பயன்படுத்திய ஆதாரங்களை வைத்திருக்கவும். இந்த வழிகாட்டி தயாரிப்பை அறிமுகப்படுத்துகிறது; CLI-க்கு தொகுப்பின் தொழில்நுட்ப README மற்றும் கட்டளைக் குறிப்பே அதிகாரப்பூர்வமானவை.

## உங்களுக்கு விருப்பமான பணியிடத்துடன் தொடங்குங்கள்

[DSHREM-ஐ](https://dsh.tvijo.com/) திறக்கவும், [VS Code நீட்டிப்பு மற்றும் முனைய வழிமுறைகளைப்](https://dsh.tvijo.com/download) பெறவும், அல்லது [அமைப்புகள் விளக்கப்பட்டுள்ளன](https://dsh.tvijo.com/knowledge/settings-explained) என்பதைப் படிக்கவும். சேவையின் ஆதரிக்கப்பட்ட கணக்கு ஓட்டம் வழியாக உள்நுழையவும். வழங்குநர் API விசைகளை பகிரப்பட்ட கேள்விப்பெட்டியிலோ, பொது சிக்கலிலோ அல்லது தொகுப்பகத்திலோ ஒருபோதும் ஒட்ட வேண்டாம்.

Node.js CLI-க்கு Node 22 அல்லது அதற்குப் புதியது தேவை. உள்ளூர் checkout ஒன்றிலிருந்து:

```sh
npm install -g .
dsh login
dsh doctor
dsh chat
```

இந்தக் கட்டளை `dshrem` என்றும் கிடைக்கிறது. இந்த தொலைநிலை அரட்டை CLI பரிந்துரைக்கப்பட்ட கருவிகளை இயக்காமல் காட்டுகிறது. உள்ளூர் திருத்தம் மற்றும் கட்டளை இயக்குதல் VS Code Agent அல்லது வெளிப்படையாக அமைக்கப்பட்ட host runtime-க்கு உரியது; அவற்றுக்கு தனி அனுமதிகள் உள்ளன. [CLI உதவி](https://github.com/nikbibamon/dshrempub/blob/main/docs/HELP.md) பார்க்கவும்.

## தேர்வுகளைப் புரிந்துகொள்ளுங்கள்

**ஆதாரம் முதலில்** என்பது ஆதரிக்கப்பட்ட உண்மைகளை ஊகங்களிலிருந்து பிரிக்கிறது. **திட்டமிட்டு சரிபார்** என்பது ஒரு சிறிய திட்டத்தைக் கேட்டு, கோரிக்கையுடன் முடிவைச் சரிபார்க்கிறது. **பதிலை மறுஆய்வு செய்** என்பது ஒரு வரைவை சவால் செய்கிறது; தனி மறுஆய்வாளர் வெளிப்படையாக நியமிக்கப்படாவிட்டால் அது சுய-மறுஆய்வு ஆகும். இந்த முறைகள் எதுவும் சரியான தன்மையையோ குறைந்த token பயன்பாட்டையோ உறுதிப்படுத்தாது.

பணி முன்னமைவுகள் மீண்டும் பயன்படுத்தக்கூடிய வழிமுறைகளையும் சரிபார்ப்புப் பட்டியல்களையும் சேர்க்கின்றன. அவை கூடுதல் மாதிரி நினைவகத்தை உருவாக்குவதில்லை. பெரிய context தொகுப்பும் சேவை மற்றும் மாதிரி கோரிக்கை வரம்புகளுக்குள் பொருந்த வேண்டும். மேம்பட்ட controller, Python மற்றும் state பாதைகள் தேர்ந்தெடுக்கப்பட்ட நீட்டிப்பு host-ஐக் குறிக்கின்றன; Remote SSH-இல் அது தொலைநிலை சேவையகம் ஆகும்.

## உதவும் போது குழுவுடன் பணியாற்றுங்கள்

ஒரு AGENTROY குழு ஒரு ஒருங்கிணைப்பாளருக்கும், செயல்படுத்துபவர்களுக்கும், மறுஆய்வாளர்களுக்கும் தனித்தனி பொறுப்புகளை ஒதுக்குகிறது. Host கொள்கைகள் DSHREM ds41f மற்றும் கணக்கு அடிப்படையிலான Codex அல்லது Claude கருவிகளைக் கோரலாம், விருப்பத்தேர்வு கட்டமைப்பு மறுஆய்வுடன். கிடைக்கும் தன்மை நிறுவப்பட்ட runtime, கணக்கு அணுகல் மற்றும் தேர்ந்தெடுக்கப்பட்ட கொள்கையைப் பொறுத்தது. இல்லாத சந்தா அமைதியாக கட்டண API அழைப்பாக மாறக்கூடாது.

மூன்று முதல் ஆறு பங்குகள் அமைப்புத் தேர்வுகள், தரமான சூத்திரம் அல்ல. மறுஆய்வாளர்களுக்கு சரியான artifact பதிப்பும் சோதனை ஆதாரமும் தேவை. மாதிரிகள் ஒத்துக்கொண்டாலும் தீவிரமான தோல்வியடைந்த சரிபார்ப்பு ஏற்றுக்கொள்ளலைத் தடுக்கிறது. [agent குழுக்கள் மற்றும் காணக்கூடிய செலவுகள்](https://dsh.tvijo.com/knowledge/agentroy-teams-and-costs) படிக்கவும்.

## நிச்சயமற்ற தன்மையை மறைக்காமல் தொடருங்கள்

ஒரு detached சேவையகப் பக்க tmux அமர்வு மடிக்கணினி அல்லது தொலைபேசி இணைப்பு துண்டிக்கப்பட்ட பிறகும் தொடரலாம். மின்சாரம் அணைக்கப்பட்ட உள்ளூர் கணினியில் வேலை தொடர முடியாது. சேவையகத் தோல்வி, நினைவக அழுத்தம் மற்றும் சேமிப்பு இழப்பு ஆகியவற்றுக்கு இன்னும் மீட்பு தேவை. சேமிக்கப்பட்ட பணி ID-க்கு மீண்டும் இணைந்து, மேலும் வேலை தொடங்கும் முன் அதன் கடைசி உறுதிப்படுத்தப்பட்ட நிகழ்வைப் பரிசீலிக்கவும். முடிவு தெரியாத கட்டணக் கோரிக்கையை கண்மூடித்தனமாக மீண்டும் செய்ய வேண்டாம். [இணைப்புத்துண்டிப்புகள் மற்றும் மீட்பு](https://dsh.tvijo.com/knowledge/durable-work-and-recovery) பார்க்கவும்.

## செலவுகளையும் தரவையும் தெரியும்படி வைத்திருங்கள்

ஏற்றுக்கொள்ளப்பட்ட மேற்கோள், பணி வரம்பு, ஒதுக்கப்பட்ட தொகை மற்றும் பயன்பாட்டு ரசீதைப் பரிசீலிக்கவும். 8% சேவை மார்க்அப் USD1.00 வழங்குநர் பயன்பாட்டை, தனியாக வெளிப்படுத்தப்பட்ட கட்டணங்களுக்கு முன் USD1.08 ஆக மாற்றும்; இது ஒரு உதாரணம், விலை சலுகை அல்ல. சந்தா ஒதுக்கீடுகள், வழங்குநர் கட்டணங்கள் மற்றும் சேவையக வளங்கள் வெவ்வேறு வரம்புகள். கூடுதல் பட்ஜெட்டுக்கு வெளிப்படையான தேர்வு தேவை.

உள்ளூர் CLI சான்றுக் கோப்புகள் உரிமையாளர்-மட்டும் அனுமதிகளைப் பயன்படுத்துகின்றன. இந்த அனுமதிகள் மறையாக்கமோ காப்புப்பிரதியோ அல்ல. அறிவு பதிவேற்றம் வெளிப்படையானது; தனிப்பட்ட கோப்புகள் ஒருபோதும் பொது handoff இணைப்பில் நுழையக்கூடாது. [Prompt handoffs](https://dsh.tvijo.com/knowledge/prompt-handoffs) என்பது மறுஆய்வு செய்யப்பட்ட பணியை மற்றொரு கருவிக்கு நகலெடுப்பதை விளக்குகிறது.

இந்தத் தொகுப்பகத்தின் package தற்போது `UNLICENSED` எனக் குறிக்கப்பட்டுள்ளது; வெளியீடு மீண்டும் பயன்படுத்தும் உரிமைகளை வழங்காது. மறுபங்கீட்டுக்கு முன் தற்போதைய package metadata மற்றும் உரிமக் குறிப்பைப் பார்க்கவும். மொழிபெயர்ப்புகள் DSHREM மூலம் உருவாக்கப்பட்டு, கட்டமைப்பு ஒருமைப்பாட்டுக்காக சரிபார்க்கப்பட்ட அறிமுக வழிகாட்டிகள்; தொழில்நுட்ப வேறுபாடுகளுக்கு ஆங்கிலமே குறிப்புத் தரநிலை.
