# Tvijo DSHREM — ایک کام سے جانچے گئے نتیجے تک

[English](README.en.md) · [Русский](README.ru.md) · [All languages / Все языки](../../README.md#read-the-introductory-guide-in-your-language)

Tvijo ایک مشترکہ ڈیولپمنٹ ورک فلو کے گرد براؤزر ورک اسپیس، VS Code ایکسٹینشن اور ٹرمینل ٹولز فراہم کرتا ہے۔ کام کی وضاحت کریں، اس کا ایگزیکیوشن ہوسٹ اور اجازتیں منتخب کریں، تبدیلیوں کا جائزہ لیں، اور نتیجہ قبول کرنے کے لیے استعمال ہونے والے ثبوت محفوظ رکھیں۔ یہ گائیڈ پروڈکٹ کا تعارف کراتی ہے؛ CLI کے لیے ریپوزٹری کا تکنیکی README اور کمانڈ ریفرنس مستند حوالہ رہیں گے۔

## اپنے پسندیدہ ورک اسپیس سے آغاز کریں

[DSHREM](https://dsh.tvijo.com/) کھولیں، [VS Code ایکسٹینشن اور ٹرمینل ہدایات](https://dsh.tvijo.com/download) حاصل کریں، یا [settings explained](https://dsh.tvijo.com/knowledge/settings-explained) پڑھیں۔ سروس کے معاون اکاؤنٹ فلو کے ذریعے سائن اِن کریں۔ پرووائیڈر API کیز کبھی بھی مشترکہ پرامپٹ، عوامی ایشو یا ریپوزٹری میں نہ پیسٹ کریں۔

Node.js CLI کے لیے Node 22 یا اس سے نیا ورژن درکار ہے۔ لوکل چیک آؤٹ سے:

```sh
npm install -g .
dsh login
dsh doctor
dsh chat
```

یہ کمانڈ `dshrem` کے نام سے بھی دستیاب ہے۔ یہ ریموٹ چیٹ CLI تجویز کردہ ٹولز دکھاتا ہے مگر انہیں چلاتا نہیں۔ لوکل ایڈیٹنگ اور کمانڈ ایگزیکیوشن VS Code Agent یا واضح طور پر کنفیگر کیے گئے ہوسٹ رن ٹائم کا حصہ ہیں؛ ان کی اجازتیں الگ ہیں۔ [CLI help](https://github.com/nikbibamon/dshrempub/blob/main/docs/HELP.md) دیکھیں۔

## انتخاب کو سمجھیں

**Evidence first** معاون حقائق کو مفروضوں سے الگ کرتا ہے۔ **Plan and check** ایک مختصر منصوبہ طلب کرتا ہے اور نتیجے کو درخواست کے مطابق جانچتا ہے۔ **Review the answer** ڈرافٹ کو چیلنج کرتا ہے؛ یہ خود جائزہ ہے جب تک الگ ریویور واضح طور پر مقرر نہ کیا جائے۔ ان میں سے کوئی بھی طریقہ درستگی یا کم ٹوکن استعمال کی ضمانت نہیں دیتا۔

ٹاسک پریسیٹس دوبارہ استعمال کے قابل ہدایات اور چیک لسٹس شامل کرتے ہیں۔ وہ ماڈل کی اضافی میموری نہیں بناتے۔ بڑا context collection پھر بھی سروس اور ماڈل کی درخواست حدود میں فٹ ہونا ضروری ہے۔ Advanced controller، Python اور state paths منتخب کردہ ایکسٹینشن ہوسٹ سے متعلق ہیں؛ Remote SSH میں وہی ریموٹ سرور ہے۔

## جب مفید ہو تو ٹیم کے ساتھ کام کریں

AGENTROY ٹیم ایک کوآرڈینیٹر، implementers اور reviewers کو الگ الگ ذمہ داریاں تفویض کرتی ہے۔ ہوسٹ پالیسیاں DSHREM ds41f اور اکاؤنٹ پر مبنی Codex یا Claude ٹولز کی درخواست کر سکتی ہیں، جس میں اختیاری معماری جائزہ شامل ہو سکتا ہے۔ دستیابی انسٹال شدہ رن ٹائم، اکاؤنٹ رسائی اور منتخب کردہ پالیسی پر منحصر ہے۔ غیر موجود سبسکرپشن خاموشی سے ادا شدہ API کال میں تبدیل نہیں ہونی چاہیے۔

تین سے چھ کردار تنظیمی انتخاب ہیں، معیار کا کوئی فارمولا نہیں۔ ریویورز کو آرٹیفیکٹ کا درست ورژن اور ٹیسٹ ثبوت درکار ہوتا ہے۔ سنگین ناکام چیک قبولیت کو روکتا ہے چاہے ماڈلز متفق ہوں۔ [agent teams and visible costs](https://dsh.tvijo.com/knowledge/agentroy-teams-and-costs) پڑھیں۔

## غیر یقینی صورتحال چھپائے بغیر دوبارہ شروع کریں

سرور سائیڈ کا detached tmux سیشن لیپ ٹاپ یا فون کے منقطع ہونے کے بعد بھی جاری رہ سکتا ہے۔ بند (powered-off) لوکل کمپیوٹر پر کام جاری نہیں رہ سکتا۔ سرور کی ناکامی، میموری پریشر اور اسٹوریج کا ضیاع پھر بھی ریکوری کا تقاضا کرتے ہیں۔ محفوظ شدہ ٹاسک ID سے دوبارہ جڑیں اور مزید کام شروع کرنے سے پہلے اس کا آخری تصدیق شدہ ایونٹ دیکھیں۔ جس بل ایبل درخواست کا نتیجہ نامعلوم ہو، اسے اندھا دھند دہرائیں نہیں۔ [disconnects and recovery](https://dsh.tvijo.com/knowledge/durable-work-and-recovery) دیکھیں۔

## اخراجات اور ڈیٹا نظر میں رکھیں

قبول شدہ کوٹ، ٹاسک کیپ، مخصوص رقم اور usage receipt کا جائزہ لیں۔ 8% سروس مارک اپ USD1.00 پرووائیڈر استعمال کو، الگ سے ظاہر کردہ چارجز سے پہلے، USD1.08 بنا دے گا؛ یہ صرف ایک مثال ہے، قیمت کی پیشکش نہیں۔ سبسکرپشن کوٹے، پرووائیڈر چارجز اور سرور وسائل مختلف حدود ہیں۔ اضافی بجٹ کے لیے واضح انتخاب درکار ہے۔

لوکل CLI کریڈنشل فائلیں صرف مالک کے لیے اجازتوں (owner-only permissions) استعمال کرتی ہیں۔ یہ اجازتیں انکرپشن یا بیک اپ نہیں ہیں۔ Knowledge اپ لوڈ واضح ہوتا ہے؛ نجی فائلیں کبھی بھی عوامی handoff لنک میں شامل نہیں ہونی چاہئیں۔ [Prompt handoffs](https://dsh.tvijo.com/knowledge/prompt-handoffs) بتاتا ہے کہ جائزہ شدہ ٹاسک کو کسی دوسرے ٹول میں کیسے نقل کیا جائے۔

اس ریپوزٹری کا پیکج فی الحال `UNLICENSED` کے طور پر نشان زد ہے؛ اشاعت دوبارہ استعمال کے حقوق نہیں دیتی۔ دوبارہ تقسیم سے پہلے موجودہ پیکیج میٹا ڈیٹا اور لائسنسنگ نوٹس سے رجوع کریں۔ تراجم تعارفی گائیڈز ہیں، جو DSHREM سے تیار کیے جاتے ہیں اور ساختی ہم آہنگی کے لیے جانچے جاتے ہیں؛ تکنیکی اختلافات کے لیے انگریزی حوالہ ہے۔
