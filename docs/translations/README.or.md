# Tvijo DSHREM — ଏକ କାର୍ଯ୍ୟରୁ ଯାଞ୍ଚ ହୋଇଥିବା ଫଳାଫଳ ପର୍ଯ୍ୟନ୍ତ

Tvijo ଏକ ସାମ୍ପ୍ରତିକ ବିକାଶ କାର୍ଯ୍ୟପ୍ରଣାଳୀ ଚାରିପାଖରେ ଏକ ବ୍ରାଉଜର ୱାର୍କସ୍ପେସ୍, ଏକ VS Code ଏକ୍ସଟେନସନ୍ ଏବଂ ଟର୍ମିନାଲ୍ ଉପକରଣ ଏକତ୍ର କରେ। କାର୍ଯ୍ୟକୁ ବର୍ଣ୍ଣନା କରନ୍ତୁ, ଏହାର ନିଷ୍ପାଦନ ହୋଷ୍ଟ ଏବଂ ଅନୁମତିଗୁଡ଼ିକୁ ବାଛନ୍ତୁ, ପରିବର୍ତ୍ତନଗୁଡ଼ିକୁ ପରୀକ୍ଷା କରନ୍ତୁ, ଏବଂ ଫଳାଫଳକୁ ସ୍ୱୀକାର କରିବା ପାଇଁ ବ୍ୟବହୃତ ପ୍ରମାଣ ରଖନ୍ତୁ। ଏହି ଗାଇଡ୍ ଉତ୍ପାଦର ପରିଚୟ ଦିଏ; CLI ପାଇଁ ରେପୋଜିଟରୀର ବୈଷୟିକ README ଏବଂ କମାଣ୍ଡ ସନ୍ଦର୍ଭ ହିଁ ପ୍ରାମାଣିକ ରହେ।

## ଆପଣଙ୍କ ପସନ୍ଦର ୱାର୍କସ୍ପେସ୍ ସହିତ ଆରମ୍ଭ କରନ୍ତୁ

[DSHREM](https://dsh.tvijo.com/) ଖୋଲନ୍ତୁ, [VS Code ଏକ୍ସଟେନସନ୍ ଏବଂ ଟର୍ମିନାଲ୍ ନିର୍ଦ୍ଦେଶାବଳୀ](https://dsh.tvijo.com/download) ନିଅନ୍ତୁ, କିମ୍ବା [ସେଟିଂସ୍ ବୁଝାଯାଇଛି](https://dsh.tvijo.com/knowledge/settings-explained) ପଢ଼ନ୍ତୁ। ସେବାର ସମର୍ଥିତ ଆକାଉଣ୍ଟ ପ୍ରବାହ ମାଧ୍ୟମରେ ସାଇନ୍ ଇନ୍ କରନ୍ତୁ। ପ୍ରୋଭାଇଡର୍ API କୀଗୁଡ଼ିକୁ କେବେ ବି ସେୟାର୍ କରାଯାଇଥିବା ପ୍ରମ୍ପ୍ଟ, ସାର୍ବଜନୀନ ଇସ୍ୟୁ କିମ୍ବା ରେପୋଜିଟରୀରେ ପେଷ୍ଟ କରନ୍ତୁ ନାହିଁ।

Node.js CLI ପାଇଁ Node 22 କିମ୍ବା ତାହାଠାରୁ ନୂଆ ସଂସ୍କରଣ ଆବଶ୍ୟକ। ସ୍ଥାନୀୟ ଚେକ୍ଆଉଟ୍‌ରୁ:

```sh
npm install -g .
dsh login
dsh doctor
dsh chat
```

ଏହି କମାଣ୍ଡ `dshrem` ଭାବରେ ମଧ୍ୟ ଉପଲବ୍ଧ। ଏହି ରିମୋଟ୍ ଚାଟ୍ CLI ପରାମର୍ଶିତ ଉପକରଣଗୁଡ଼ିକୁ ଦର୍ଶାଏ କିନ୍ତୁ ସେଗୁଡ଼ିକୁ ଚଲାଏ ନାହିଁ। ସ୍ଥାନୀୟ ଏଡିଟିଂ ଏବଂ କମାଣ୍ଡ ନିଷ୍ପାଦନ VS Code Agent କିମ୍ବା ସ୍ପଷ୍ଟ ଭାବରେ ବିନ୍ୟାସିତ ହୋଷ୍ଟ ରନ୍‌ଟାଇମ୍‌ର ଅଟେ; ସେଗୁଡ଼ିକର ଅଲଗା ଅନୁମତି ଅଛି। [CLI ସହାୟତା](https://github.com/nikbibamon/dshrempub/blob/main/docs/HELP.md) ଦେଖନ୍ତୁ।

## ବିକଳ୍ପଗୁଡ଼ିକୁ ବୁଝନ୍ତୁ

**ପ୍ରମାଣ ପ୍ରଥମେ** ସମର୍ଥିତ ତଥ୍ୟକୁ ଅନୁମାନରୁ ଅଲଗା କରେ। **ଯୋଜନା ଏବଂ ଯାଞ୍ଚ** ଏକ ସଂକ୍ଷିପ୍ତ ଯୋଜନା ମାଗେ ଏବଂ ଅନୁରୋଧ ସହିତ ଫଳାଫଳକୁ ଯାଞ୍ଚ କରେ। **ଉତ୍ତର ସମୀକ୍ଷା** ଏକ ଡ୍ରାଫ୍ଟକୁ ଚ୍ୟାଲେଞ୍ଜ କରେ; ଯଦି ଅଲଗା ସମୀକ୍ଷକ ସ୍ପଷ୍ଟ ଭାବରେ ନିଯୁକ୍ତ ନ ହୁଏ, ତେବେ ଏହା ସ୍ୱ-ସମୀକ୍ଷା। ଏହି ପଦ୍ଧତିଗୁଡ଼ିକ ମଧ୍ୟରୁ କୌଣସିଟି ସଠିକତା କିମ୍ବା କମ୍ ଟୋକେନ୍ ବ୍ୟବହାରର ଗ୍ୟାରେଣ୍ଟି ଦିଏ ନାହିଁ।

କାର୍ଯ୍ୟ ପ୍ରିସେଟ୍‌ଗୁଡ଼ିକ ପୁନଃବ୍ୟବହାରଯୋଗ୍ୟ ନିର୍ଦ୍ଦେଶ ଏବଂ ଚେକଲିଷ୍ଟ ଯୋଡ଼େ। ସେଗୁଡ଼ିକ ଅତିରିକ୍ତ ମଡେଲ୍ ସ୍ମୃତି ସୃଷ୍ଟି କରେ ନାହିଁ। ଏକ ବଡ଼ ପ୍ରସଙ୍ଗ ସଂଗ୍ରହ ତଥାପି ସେବା ଏବଂ ମଡେଲ୍ ଅନୁରୋଧ ସୀମା ମଧ୍ୟରେ ରହିବାକୁ ପଡ଼ିବ। ଉନ୍ନତ କଣ୍ଟ୍ରୋଲର୍, Python ଏବଂ state ପଥଗୁଡ଼ିକ ମନୋନୀତ ଏକ୍ସଟେନସନ୍ ହୋଷ୍ଟକୁ ସୂଚାଏ; Remote SSHରେ ତାହା ରିମୋଟ୍ ସର୍ଭର୍ ଅଟେ।

## ଯେତେବେଳେ ସାହାଯ୍ୟ କରେ ସେତେବେଳେ ଏକ ଟିମ୍ ସହିତ କାମ କରନ୍ତୁ

ଏକ AGENTROY ଟିମ୍ ଜଣେ ସଂଯୋଜକ, କାର୍ଯ୍ୟକାରୀ ଏବଂ ସମୀକ୍ଷକଙ୍କୁ ଅଲଗା ଅଲଗା ଦାୟିତ୍ୱ ଦିଏ। ହୋଷ୍ଟ ନୀତିଗୁଡ଼ିକ DSHREM ds41f ଏବଂ ଆକାଉଣ୍ଟ-ଆଧାରିତ Codex କିମ୍ବା Claude ଉପକରଣ ଅନୁରୋଧ କରିପାରେ, ବୈକଳ୍ପିକ ସ୍ଥାପତ୍ୟ ସମୀକ୍ଷା ସହିତ। ଉପଲବ୍ଧତା ସ୍ଥାପିତ ରନ୍‌ଟାଇମ୍, ଆକାଉଣ୍ଟ ପ୍ରବେଶ ଏବଂ ମନୋନୀତ ନୀତି ଉପରେ ନିର୍ଭର କରେ। ଏକ ଅନୁପସ୍ଥିତ ସବସ୍କ୍ରିପ୍ସନ୍ ନିଶ୍ଚିତ ଭାବରେ ଏକ ପେଡ୍ API କଲ୍ ହୋଇଯିବା ଉଚିତ ନୁହେଁ।

ତିନିରୁ ଛଅ ଭୂମିକା ସଂଗଠନ ପସନ୍ଦ, ଗୁଣବତ୍ତା ସୂତ୍ର ନୁହେଁ। ସମୀକ୍ଷକମାନଙ୍କୁ ସଠିକ୍ ଆର୍ଟିଫ୍ୟାକ୍ଟ ସଂସ୍କରଣ ଏବଂ ପରୀକ୍ଷା ପ୍ରମାଣ ଆବଶ୍ୟକ। ମଡେଲ୍‌ମାନେ ସହମତ ହେଲେ ମଧ୍ୟ ଏକ ଗୁରୁତର ବିଫଳ ଯାଞ୍ଚ ସ୍ୱୀକୃତିକୁ ଅବରୋଧ କରେ। [ଏଜେଣ୍ଟ ଟିମ୍ ଏବଂ ଦୃଶ୍ୟମାନ ଖର୍ଚ୍ଚ](https://dsh.tvijo.com/knowledge/agentroy-teams-and-costs) ପଢ଼ନ୍ତୁ।

## ଅନିଶ୍ଚିତତା ଲୁଚାଇ ନ ରଖି ପୁନଃଆରମ୍ଭ କରନ୍ତୁ

ଏକ ଡିଟ୍ୟାଚ୍ ହୋଇଥିବା ସର୍ଭର-ପାର୍ଶ୍ୱ tmux ସେସନ୍ ଲାପଟପ୍ କିମ୍ବା ଫୋନ୍ ବିଚ୍ଛିନ୍ନ ହେବା ପରେ ମଧ୍ୟ ଜାରି ରହିପାରେ। ବନ୍ଦ ଥିବା ସ୍ଥାନୀୟ କମ୍ପ୍ୟୁଟରରେ କାମ ଜାରି ରହିପାରିବ ନାହିଁ। ସର୍ଭର ବିଫଳତା, ମେମୋରୀ ଚାପ ଏବଂ ଷ୍ଟୋରେଜ୍ କ୍ଷତି ପାଇଁ ତଥାପି ପୁନରୁଦ୍ଧାର ଆବଶ୍ୟକ। ସଂରକ୍ଷିତ କାର୍ଯ୍ୟ ID ସହିତ ପୁନଃସଂଯୋଗ କରନ୍ତୁ ଏବଂ ଅଧିକ କାମ ଆରମ୍ଭ କରିବା ପୂର୍ବରୁ ଏହାର ଶେଷ ନିଶ୍ଚିତ ଘଟଣାକୁ ପରୀକ୍ଷା କରନ୍ତୁ। ଯାହାର ଫଳାଫଳ ଅଜ୍ଞାତ, ଏପରି ଏକ ବିଲ୍‌ଯୋଗ୍ୟ ଅନୁରୋଧକୁ ଅନ୍ଧଭାବରେ ପୁନରାବୃତ୍ତି କରନ୍ତୁ ନାହିଁ। [ବିଚ୍ଛିନ୍ନତା ଏବଂ ପୁନରୁଦ୍ଧାର](https://dsh.tvijo.com/knowledge/durable-work-and-recovery) ଦେଖନ୍ତୁ।

## ଖର୍ଚ୍ଚ ଏବଂ ତଥ୍ୟ ଦୃଶ୍ୟମାନ ରଖନ୍ତୁ

ସ୍ୱୀକୃତ କୋଟ୍, କାର୍ଯ୍ୟ ସୀମା, ସଂରକ୍ଷିତ ରାଶି ଏବଂ ବ୍ୟବହାର ରସିଦ ସମୀକ୍ଷା କରନ୍ତୁ। 8% ସେବା ମାର୍କଅପ୍ USD1.00 ପ୍ରୋଭାଇଡର୍ ବ୍ୟବହାରକୁ ଅଲଗା ଭାବରେ ପ୍ରକାଶିତ ଚାର୍ଜ ପୂର୍ବରୁ USD1.08 କରିଦେବ; ଏହା ଏକ ଉଦାହରଣ, ମୂଲ୍ୟ ପ୍ରସ୍ତାବ ନୁହେଁ। ସବସ୍କ୍ରିପ୍ସନ୍ କୋଟା, ପ୍ରୋଭାଇଡର୍ ଚାର୍ଜ ଏବଂ ସର୍ଭର ସମ୍ବଳ ଅଲଗା ଅଲଗା ସୀମା। ଅତିରିକ୍ତ ବଜେଟ୍ ପାଇଁ ସ୍ପଷ୍ଟ ପସନ୍ଦ ଆବଶ୍ୟକ।

ସ୍ଥାନୀୟ CLI କ୍ରେଡେନ୍‌ସିଆଲ୍ ଫାଇଲ୍‌ଗୁଡ଼ିକ କେବଳ-ମାଲିକ ଅନୁମତି ବ୍ୟବହାର କରେ। ଏହି ଅନୁମତିଗୁଡ଼ିକ ଏନକ୍ରିପ୍ସନ୍ କିମ୍ବା ବ୍ୟାକଅପ୍ ନୁହେଁ। ନଲେଜ୍ ଅପଲୋଡ୍ ସ୍ପଷ୍ଟ; ଘରୋଇ ଫାଇଲ୍‌ଗୁଡ଼ିକ କେବେ ବି ସାର୍ବଜନୀନ ହ୍ୟାଣ୍ଡଅଫ୍ ଲିଙ୍କ୍‌ରେ ପ୍ରବେଶ କରିବା ଉଚିତ ନୁହେଁ। [ପ୍ରମ୍ପ୍ଟ ହ୍ୟାଣ୍ଡଅଫ୍](https://dsh.tvijo.com/knowledge/prompt-handoffs) ଏକ ସମୀକ୍ଷିତ କାର୍ଯ୍ୟକୁ ଅନ୍ୟ ଉପକରଣରେ କିପରି କପି କରିବେ ତାହା ବ୍ୟାଖ୍ୟା କରେ।

ଏହି ରେପୋଜିଟରୀର ପ୍ୟାକେଜ୍ ବର୍ତ୍ତମାନ `UNLICENSED` ଭାବରେ ଚିହ୍ନିତ; ପ୍ରକାଶନ ପୁନଃବ୍ୟବହାର ଅଧିକାର ପ୍ରଦାନ କରେ ନାହିଁ। ପୁନଃବଣ୍ଟନ ପୂର୍ବରୁ ବର୍ତ୍ତମାନର ପ୍ୟାକେଜ୍ ମେଟାଡାଟା ଏବଂ ଲାଇସେନ୍ସିଂ ସୂଚନା ଦେଖନ୍ତୁ। ଅନୁବାଦଗୁଡ଼ିକ ପରିଚୟାତ୍ମକ ଗାଇଡ୍, DSHREM ସହିତ ଉତ୍ପାଦିତ ଏବଂ ଗଠନାତ୍ମକ ସଙ୍ଗତି ପାଇଁ ଯାଞ୍ଚ କରାଯାଇଛି; ବୈଷୟିକ ଅସଙ୍ଗତି ପାଇଁ ଇଂରାଜୀ ହିଁ ସନ୍ଦର୍ଭ।
