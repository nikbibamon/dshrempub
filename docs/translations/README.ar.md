# Tvijo DSHREM — من مهمة إلى نتيجة مُتحقَّق منها

[English](README.en.md) · [Русский](README.ru.md) · [All languages / Все языки](../../README.md#read-the-introductory-guide-in-your-language)

يجمع Tvijo مساحة عمل في المتصفح، وإضافة VS Code، وأدوات طرفية حول سير عمل تطويري مشترك. صِف المهمة، واختر مضيف تنفيذها وأذوناتها، وافحص التغييرات، واحتفظ بالأدلة المستخدمة لقبول النتيجة. يقدّم هذا الدليل المنتج؛ ويبقى README التقني في المستودع ومرجع الأوامر هما المرجع المعتمد لواجهة سطر الأوامر.

## ابدأ بمساحة العمل المفضلة لديك

افتح [DSHREM](https://dsh.tvijo.com/)، أو احصل على [إضافة VS Code وتعليمات الطرفية](https://dsh.tvijo.com/download)، أو اقرأ [شرح الإعدادات](https://dsh.tvijo.com/knowledge/settings-explained). سجّل الدخول عبر مسار الحساب المدعوم في الخدمة. لا تلصق أبدًا مفاتيح API الخاصة بمزوّد الخدمة في مطالبة مشتركة أو مشكلة عامة أو مستودع.

تتطلب أداة سطر الأوامر Node.js الإصدار Node 22 أو أحدث. من نسخة محلية من المستودع:

```sh
npm install -g .
dsh login
dsh doctor
dsh chat
```

الأمر متاح أيضًا باسم `dshrem`. تعرض أداة سطر الأوامر هذه للمحادثة البعيدة الأدوات المقترحة دون تنفيذها. أما التحرير المحلي وتنفيذ الأوامر فيتبعان لـ VS Code Agent أو لبيئة تشغيل مضيف مُهيّأة صراحةً؛ ولهما أذونات منفصلة. راجع [مساعدة CLI](https://github.com/nikbibamon/dshrempub/blob/main/docs/HELP.md).

## افهم الخيارات

**الأدلة أولًا** تفصل الحقائق المدعومة عن الافتراضات. **التخطيط والتحقق** يطلب خطة قصيرة ويتحقق من النتيجة مقابل الطلب. **مراجعة الإجابة** تطعن في المسودة؛ وهي مراجعة ذاتية ما لم يُعيَّن مراجع منفصل صراحةً. لا يضمن أي من هذه الأساليب الصحة ولا استخدامًا أقل للرموز.

تضيف إعدادات المهام المسبقة تعليمات وقوائم تحقق قابلة لإعادة الاستخدام. وهي لا تنشئ ذاكرة إضافية للنموذج. ولا يزال يتعيّن على مجموعة السياق الأكبر أن تتوافق مع حدود الطلبات الخاصة بالخدمة والنموذج. تشير مسارات المتحكم وPython والحالة المتقدمة إلى مضيف الإضافة المحدد؛ وفي Remote SSH يكون ذلك هو الخادم البعيد.

## اعمل ضمن فريق عندما يفيد ذلك

يُسند فريق AGENTROY إلى منسّق ومنفّذين ومراجعين مسؤوليات متمايزة. قد تطلب سياسات المضيف أدوات DSHREM ds41f وأدوات Codex أو Claude القائمة على الحساب، مع مراجعة معمارية اختيارية. يتوقف مدى التوافر على بيئة التشغيل المثبَّتة والوصول إلى الحساب والسياسة المختارة. ويجب ألّا يتحول اشتراك مفقود بصمت إلى استدعاء API مدفوع.

اختيار ثلاثة إلى ستة أدوار هو قرار تنظيمي، لا معادلة جودة. يحتاج المراجعون إلى النسخة الدقيقة من الأثر وإلى أدلة الاختبار. الاختبار الفاشل الجسيم يمنع القبول حتى عندما تتفق النماذج. اقرأ [فرق الوكلاء والتكاليف المرئية](https://dsh.tvijo.com/knowledge/agentroy-teams-and-costs).

## استأنف دون إخفاء عدم اليقين

يمكن لجلسة tmux منفصلة على الخادم أن تستمر بعد انقطاع حاسوب محمول أو هاتف. أما العمل على حاسوب محلي مُغلق فلا يمكن أن يستمر. ولا يزال فشل الخادم وضغط الذاكرة وفقدان التخزين تتطلب الاستعادة. أعد الاتصال بمعرّف المهمة المحفوظ وافحص آخر حدث مؤكَّد فيها قبل بدء مزيد من العمل. لا تكرر بلا تمييز طلبًا قابلًا للفوترة نتيجته غير معروفة. راجع [الانقطاعات والاستعادة](https://dsh.tvijo.com/knowledge/durable-work-and-recovery).

## أبقِ التكاليف والبيانات مرئية

راجع عرض السعر المقبول وحدّ المهمة والمبلغ المحجوز وإيصال الاستخدام. سيحوّل هامش خدمة بنسبة 8% استخدامًا من المزوّد بقيمة USD1.00 إلى USD1.08 قبل الرسوم المفصح عنها بشكل منفصل؛ وهذا مثال، لا عرض سعر. حصص الاشتراك ورسوم المزوّد وموارد الخادم حدود مختلفة. وتتطلب الميزانية الإضافية اختيارًا صريحًا.

تستخدم ملفات بيانات الاعتماد المحلية لواجهة سطر الأوامر أذونات مقصورة على المالك. وهذه الأذونات ليست تشفيرًا ولا نسخة احتياطية. رفع المعرفة صريح؛ ولا ينبغي أن تدخل الملفات الخاصة أبدًا في رابط تسليم عام. توضح [عمليات تسليم المطالبات](https://dsh.tvijo.com/knowledge/prompt-handoffs) كيفية نسخ مهمة مُراجَعة إلى أداة أخرى.

حزمة هذا المستودع مُعلَّمة حاليًا بـ `UNLICENSED`؛ والنشر لا يمنح حقوق إعادة الاستخدام. راجع بيانات تعريف الحزمة الحالية وإشعار الترخيص قبل إعادة التوزيع. الترجمات هي أدلة تمهيدية، تُولَّد باستخدام DSHREM وتُفحص من حيث الاتساق البنيوي؛ والإنجليزية هي المرجع في حال وجود اختلافات تقنية.
