# Tvijo DSHREM — از یک وظیفه تا نتیجهٔ بررسیشده

[English](README.en.md) · [Русский](README.ru.md) · [All languages / Все языки](../../README.md#read-the-introductory-guide-in-your-language)

Tvijo یک محیط کاری مرورگری، یک افزونهٔ VS Code و ابزارهای خط فرمان را حول یک گردش‌کار توسعهٔ مشترک گرد هم می‌آورد. وظیفه را شرح دهید، میزبان اجرا و مجوزهای آن را انتخاب کنید، تغییرات را بررسی کنید و شواهدی را که برای پذیرش نتیجه استفاده شده نگه دارید. این راهنما محصول را معرفی می‌کند؛ README فنی مخزن و مرجع فرمان‌ها برای CLI همچنان مرجع نهایی‌اند.

## با محیط کاری ترجیحی خود شروع کنید

[DSHREM](https://dsh.tvijo.com/) را باز کنید، [افزونهٔ VS Code و دستورالعمل‌های ترمینال](https://dsh.tvijo.com/download) را دریافت کنید، یا [توضیح تنظیمات](https://dsh.tvijo.com/knowledge/settings-explained) را بخوانید. از طریق جریان حساب پشتیبانی‌شدهٔ سرویس وارد شوید. هرگز کلیدهای API ارائه‌دهنده را در یک اعلان مشترک، issue عمومی یا مخزن قرار ندهید.

CLI ‏Node.js به Node 22 یا جدیدتر نیاز دارد. از یک نسخهٔ محلی مخزن:

```sh
npm install -g .
dsh login
dsh doctor
dsh chat
```

این فرمان با نام `dshrem` نیز در دسترس است. این CLI چت از راه دور ابزارهای پیشنهادی را نمایش می‌دهد بدون آنکه آن‌ها را اجرا کند. ویرایش محلی و اجرای فرمان متعلق به VS Code Agent یا یک runtime میزبان است که به‌صراحت پیکربندی شده باشد؛ آن‌ها مجوزهای جداگانه دارند. [راهنمای CLI](https://github.com/nikbibamon/dshrempub/blob/main/docs/HELP.md) را ببینید.

## گزینه‌ها را درک کنید

**شواهد در اولویت** واقعیت‌های پشتیبانی‌شده را از فرض‌ها جدا می‌کند. **برنامه‌ریزی و بررسی** یک برنامهٔ کوتاه می‌خواهد و نتیجه را با درخواست مقایسه می‌کند. **بازبینی پاسخ** پیش‌نویس را به چالش می‌کشد؛ مگر آنکه یک بازبین جداگانه به‌صراحت تعیین شده باشد، این خودبازبینی است. هیچ‌یک از این روش‌ها درستی یا مصرف کمتر توکن را تضمین نمی‌کند.

پیش‌تنظیم‌های وظیفه دستورالعمل‌ها و چک‌لیست‌های قابل استفادهٔ مجدد را اضافه می‌کنند. آن‌ها حافظهٔ مدل اضافی ایجاد نمی‌کنند. یک مجموعهٔ بزرگ‌تر از زمینه همچنان باید در محدودیت‌های درخواست سرویس و مدل جای بگیرد. مسیرهای پیشرفتهٔ controller، Python و state به میزبان افزونهٔ انتخاب‌شده اشاره دارند؛ در Remote SSH این میزبان همان سرور از راه دور است.

## وقتی کمک می‌کند، با یک تیم کار کنید

یک تیم AGENTROY به یک هماهنگ‌کننده، پیاده‌سازان و بازبین‌ها مسئولیت‌های متمایز می‌دهد. سیاست‌های میزبان ممکن است DSHREM ds41f و ابزارهای Codex یا Claude مبتنی بر حساب را فراخوانی کنند، همراه با بازبینی معماری اختیاری. در دسترس بودن به runtime نصب‌شده، دسترسی حساب و سیاست انتخاب‌شده بستگی دارد. یک اشتراک ناموجود نباید به‌صورت خاموش به یک فراخوانی API پولی تبدیل شود.

سه تا شش نقش، انتخاب‌های سازمانی است، نه فرمولی برای کیفیت. بازبین‌ها به نسخهٔ دقیق artifact و شواهد آزمون نیاز دارند. یک بررسی شکست‌خوردهٔ جدی پذیرش را مسدود می‌کند، حتی وقتی مدل‌ها هم‌نظر باشند. [تیم‌های عامل و هزینه‌های قابل مشاهده](https://dsh.tvijo.com/knowledge/agentroy-teams-and-costs) را بخوانید.

## بدون پنهان‌کردن ابهام، ادامه دهید

یک نشست tmux جداافتاده در سمت سرور می‌تواند پس از قطع اتصال لپ‌تاپ یا تلفن ادامه یابد. کار روی یک کامپیوتر محلی که خاموش شده نمی‌تواند ادامه یابد. خرابی سرور، فشار حافظه و از دست رفتن فضای ذخیره‌سازی همچنان به بازیابی نیاز دارند. پیش از شروع کار بیشتر، به شناسهٔ وظیفهٔ ذخیره‌شده دوباره وصل شوید و آخرین رویداد تأییدشدهٔ آن را بررسی کنید. درخواست پولی‌ای که نتیجه‌اش نامعلوم است را کورکورانه تکرار نکنید. [قطع اتصال و بازیابی](https://dsh.tvijo.com/knowledge/durable-work-and-recovery) را ببینید.

## هزینه‌ها و داده‌ها را قابل مشاهده نگه دارید

پیش‌فاکتور پذیرفته‌شده، سقف وظیفه، مبلغ رزروشده و رسید مصرف را بررسی کنید. یک حاشیهٔ خدمات 8% مبلغ USD1.00 مصرف ارائه‌دهنده را پیش از هزینه‌های جداگانهٔ اعلام‌شده به USD1.08 تبدیل می‌کند؛ این یک مثال است، نه پیشنهاد قیمت. سهمیه‌های اشتراک، هزینه‌های ارائه‌دهنده و منابع سرور محدودیت‌های متفاوتی‌اند. بودجهٔ اضافی نیازمند یک انتخاب صریح است.

فایل‌های اعتبارنامهٔ CLI محلی از مجوزهای فقط‌مالک استفاده می‌کنند. این مجوزها رمزگذاری یا نسخهٔ پشتیبان نیستند. بارگذاری دانش صریح است؛ فایل‌های خصوصی هرگز نباید به یک لینک تحویل عمومی وارد شوند. [تحویل اعلان‌ها](https://dsh.tvijo.com/knowledge/prompt-handoffs) توضیح می‌دهد چگونه یک وظیفهٔ بازبینی‌شده را در ابزار دیگری کپی کنید.

بستهٔ این مخزن در حال حاضر `UNLICENSED` علامت‌گذاری شده است؛ انتشار حق استفادهٔ مجدد اعطا نمی‌کند. پیش از توزیع مجدد، فرادادهٔ فعلی بسته و اطلاعیهٔ مجوز را بررسی کنید. ترجمه‌ها راهنماهای مقدماتی‌اند که با DSHREM تولید و از نظر سازگاری ساختاری بررسی شده‌اند؛ در اختلاف‌های فنی، انگلیسی مرجع است.
