# Tvijo DSHREM — от задачи к проверенному результату

[English](README.en.md) · [Русский](README.ru.md) · [All languages / Все языки](../../README.md#read-the-introductory-guide-in-your-language)

Tvijo объединяет браузерное рабочее пространство, расширение для VS Code и терминальные инструменты вокруг общего рабочего процесса разработки. Опишите задачу, выберите хост её выполнения и разрешения, изучите изменения и сохраните доказательства, по которым результат был принят. Это руководство знакомит с продуктом; технический README репозитория и справочник команд остаются основным источником сведений о CLI.

## Начните с удобного рабочего пространства

Откройте [DSHREM](https://dsh.tvijo.com/), получите [расширение для VS Code и инструкции по работе в терминале](https://dsh.tvijo.com/download) или прочитайте [объяснение настроек](https://dsh.tvijo.com/knowledge/settings-explained). Войдите в аккаунт способом, который предлагает сервис. Никогда не вставляйте API-ключи провайдеров в общий промпт, публичный issue или репозиторий.

CLI для Node.js требует Node 22 или новее. Из локальной копии репозитория:

```sh
npm install -g .
dsh login
dsh doctor
dsh chat
```

Команда также доступна как `dshrem`. Этот удалённый чат-CLI показывает предлагаемые инструменты, но не выполняет их. Локальное редактирование файлов и выполнение команд относятся к VS Code Agent или к явно настроенной среде выполнения хоста; у них отдельные разрешения. См. [справку по CLI](https://github.com/nikbibamon/dshrempub/blob/main/docs/HELP.md).

## Разберитесь в вариантах выбора

**Сначала факты** отделяет подтверждённые факты от предположений. **План и проверка** задаёт краткого плана и сверяет результат с запросом. **Проверка ответа** оспаривает черновик; это самопроверка, если отдельный проверяющий не назначен явно. Ни один из этих методов не гарантирует правильность или меньший расход токенов.

Пресеты задач добавляют переиспользуемые инструкции и контрольные списки. Они не создают дополнительную память модели. Даже больший объём собранного контекста всё равно должна укладываться в лимиты запроса сервиса и модели. Расширенные пути контроллера, Python и состояния относятся к выбранному хосту расширения; в Remote SSH это удалённый сервер.

## Работайте в команде, когда это помогает

Команда AGENTROY распределяет между координатором, исполнителями и проверяющими разные обязанности. Политики хоста могут запрашивать DSHREM ds41f и инструменты Codex или Claude, привязанные к учётной записи, с необязательным архитектурным ревью. Доступность зависит от установленной среды выполнения, доступа к учётной записи и выбранной политики. Отсутствующая подписка не должна незаметно превращаться в платный вызов API.

Три–шесть ролей — это способ организации работы, а не формула качества. Проверяющим нужна точная версия артефакта и результаты тестов. Серьёзная проваленная проверка блокирует приёмку, даже если модели согласны друг с другом. Читайте [команды агентов и видимые затраты](https://dsh.tvijo.com/knowledge/agentroy-teams-and-costs).

## Продолжайте работу, не скрывая неопределённость

Отсоединённая серверная сессия tmux может продолжаться после отключения ноутбука или телефона. Работа на выключенном локальном компьютере продолжаться не может. Сбой сервера, нехватка памяти и потеря хранилища всё равно требуют восстановления. Переподключитесь к сохранённому ID задачи и изучите её последнее подтверждённое событие, прежде чем начинать новую работу. Не повторяйте вслепую платный запрос, исход которого неизвестен. См. [отключения и восстановление](https://dsh.tvijo.com/knowledge/durable-work-and-recovery).

## Держите затраты и данные на виду

Проверьте принятый расчёт стоимости, лимит задачи, зарезервированную сумму и квитанцию об использовании. Сервисная наценка 8% превратила бы USD1.00 использования провайдера в USD1.08 до отдельно указанных сборов; это пример, а не ценовое предложение. Квоты подписок, платежи провайдера и серверные ресурсы — разные лимиты. Дополнительный бюджет требует явного выбора.

Локальные файлы учётных данных CLI доступны только владельцу. Эти разрешения не являются шифрованием или резервной копией. Загрузка в базу знаний выполняется явно; приватные файлы никогда не должны попадать в публичную ссылку для передачи. [Передача промптов](https://dsh.tvijo.com/knowledge/prompt-handoffs) объясняет, как скопировать проверенную задачу в другой инструмент.

Пакет этого репозитория сейчас помечен как `UNLICENSED`; публикация не даёт прав на повторное использование. Перед распространением сверьтесь с текущими метаданными пакета и уведомлением о лицензировании. Переводы — это вводные руководства, созданные с помощью DSHREM и проверенные на структурную согласованность; при технических расхождениях эталон — английский текст.
