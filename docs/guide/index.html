Local or Remote SSH?

A local window uses your computer. Remote SSH uses the remote host: files, dependencies and tools must exist there. Focusing a different file does not change Tvijo’s selected execution folder.

When you need a Linux Harness host

Managed background tasks require a configured Linux runtime. The ordinary Windows Agent is a separate path.

  1. Open the prepared Linux project locally or through Remote SSH.
  2. Run Tvijo: Set up orchestration, then Tvijo: Orchestration doctor.
  3. Check the runtime, account CLI login and subscription quota. Choose Sol or Sol + Astra; the operator has paused Claude.
  4. Enable Orchestration: Enabled after setup succeeds. Subscription workers and an API coordinator have different cost rules.

Do not silently substitute an unavailable provider. If the subscription quota runs out, stop; automatic API fallback is not authorized.

One small cycle, one useful result 🔄

A narrow task is easier to finish than an open request to “improve the whole project”.

1. Plan: make the outcome checkable

Select the function or attach one source file, its test and the observed error. Run Tvijo: Run agent in plan mode. Plan reads and explains; edits and commands are disabled for that run.

Goal: [the behavior to deliver].
Current problem: [error and reproduction].
Editable paths: [exact paths]. Keep unchanged: [constraints].
Done when: [2–3 observable conditions].
Check: [existing focused test command].
First explain the cause and a short plan. Do not edit files yet.
Since 0.10.14: inspect code with editor symbols

Ask Agent or Plan to list symbols, find a definition or find references. code_intelligence uses installed VS Code language providers. The project needs a working provider for that language.

Results contain symbol metadata and locations, not the full text of every file. Lines and columns start at 1. Unavailable, empty and partial results must remain explicit; no references returned does not prove that no references exist.

Use Plan. List the symbols in src/stats.py.
Find the definition and references for average at line 12, column 5.
This is an example position: use the actual position in my file.
Do not edit code. Distinguish provider results from assumptions.
Report an unavailable provider or partial result explicitly.

This editor integration is separate from the default-off Python LSP host pilot.

2. Edit: define the boundaries

After the plan, use Tvijo: Run agent task for the agreed change. Tvijo: Quick edit the current file leaves a buffer for review and explicit saving. Agent Auto saves eligible edits before later tests.

Inspect git status --short first. Record existing work. Give concurrent agents different file allowlists or isolated worktrees. Do not let two agents edit one file at the same time.

3. Test: check the actual behavior

Start with the affected function or file, then run the repository’s required checks. If the tool cannot run a command, use the appropriate terminal and attach the result with Tvijo: Attach observed terminal output. For UI changes, exercise the scenario in a browser and at a narrow width.

Syntax success is not functional success.

Editor diagnostics, tests, builds, installed packages and production behavior are separate evidence. Record the command, exit code, date and version.

4. Review: close the task with evidence

Review only this task’s diff and acceptance criteria.
Look for defects, regressions and missing edge cases.
For each finding, give the file, trigger and checkable consequence.
Separate demonstrated errors from hypotheses.
Do not edit files or automatically start a paid council.

Review from another role changes the approach to a response; it does not itself start an independent agent. Request a separate review when complexity or risk justifies it. Repeat affected checks after corrections.

The budget is a ceiling, not a quoted price. Several local runs do not grant several new task budgets. The root task cap and existing provider caps still apply.

Terminal DSHREM uses a different loader

The CLI automatically injects AGENTS.md and AGENTS.local.md. Do not assume that the extension’s .tvijo/rules.md was loaded by the CLI. Check the installed version’s help and observed context.

Our repositories additionally require one phase at a time, an initial gate, exact write allowlists, artifacts on the volume and no heavy shared-host checks. This guide does not override those rules.

Rules are advice, not extra permissions

Command-modified rules can be quarantined and excluded from later requests. Inspect the diff and origin before re-enabling a file in Settings. Choosing a child folder does not clear quarantine.

Precise tasks save effort 📊

Measure the time to an accepted result and actual API charges. A fast reply does not necessarily finish the task faster.

Keep the useful work small

  • Ask for one bug fix or one feature stage; measure time to the accepted diff.
  • Provide the function, test and observed error; track context size and repeated attempts.
  • Run a focused check first; broaden only when the change or repository requires it.
  • Use one implementer and targeted review; include all paid workers in the task receipt.
  • Save a short handoff so the next run does not restart the investigation.

Choose a route for the task

The ordinary chat/Agent default is ds41f. Start a small fix with an available basic route and focused context. For ambiguous architecture, collect evidence first, then request a single targeted expert review. A model name in a menu does not prove availability or pricing.

For repeated identical failed attempts in our projects, one advisory Codex GPT-6.1 Sol account-CLI consultation is allowed under AGENTJUDGE evidence rules. It cannot approve its own changes or expand the budget. Claude remains paused.

Subscription quota and API money are separate.

Codex account CLI work consumes subscription quota, not a per-call API payment. Launch without OPENAI_API_KEY or ANTHROPIC_API_KEY and do not source the shared secrets file. A subscription does not make service API calls free. Quota failure does not authorize API fallback.

A cap is not a spending plan

Actual extension defaults are 60 steps, $2 and Auto. The suggested profile reduces the limit to 30 steps and the local context preview to 48,000 bytes; apply it explicitly. Lower the money ceiling for a small task when its route and scope fit.

Our ordinary operator task cap is $2 for the entire root task, including paid workers, unless explicitly changed. Restarting or increasing a local limit does not erase prior spending. Unknown cost stops the paid path; it is not $0.

Use Tvijo: Recent tasks and spending and Tvijo: Service usage and receipts. TT means service credit; model tokens measure processed text.

Why a larger context preview is not always better

The local preview default is 200,000 bytes; the generated request excerpt is limited to 60,000 bytes, with separate rules limits. Increasing the preview does not increase the model’s context window. Select relevant files and inspect the result.

Stopped? Preserve, diagnose, continue 🛟

Keep the last command, observed error and useful result. A new request is not permission to erase previous work.

Wrong version, folder or context

Check the active version in Settings and use Tvijo: Reload window. Hover over the folder button: execution follows that folder, not the most recently focused file. Stop the task before changing folders.

Attach missing files explicitly. For missing rules, check Workspace Trust, Context Off, per-file switches and quarantine.

Account, connection or budget failure

Run Tvijo: Check service connection and inspect Account and credit. Preserve the exact error without tokens. Do not bypass an account refusal, unknown cost or exhausted quota with a different paid route.

Harness status disappeared after disconnection

On the configured Linux host, run Tvijo: Orchestration status and repair queue, then Tvijo: Resume orchestration task for the original task. Check Orchestration doctor. Repair shares the original finite budget.

A reachable remote host can continue a tmux task. A powered-off local computer cannot. A lost status connection does not prove that the job finished or vanished.

Recover an unsuccessful edit with Rewind

Run Tvijo: Rewind or /rewind. Choose a run and step, then inspect affected files. Rewind restores file edits; it does not undo shell side effects or all external tool writes.

If a file contains other people’s or newer work, choose Skip file. Overwrite file and Delete file require explicit authority for those paths. Preserve both versions and inspect the diff. Checkpoints are not permanent backups.

The same attempt keeps failing

Stop repeating it. Save the task, diff, command, output, exit code, version and charges. Change one hypothesis or request one targeted consultation. Do not start an endless paid team or reactivate paused Claude.

Four meanings of “ready”

  1. Implemented: a specific code version and diff exist.
  2. Checked: dated tests and an observed scenario exist.
  3. Released: a downloadable package, version and checksum exist.
  4. Working for you: you installed it, reloaded it and completed a safe first task.

Do not claim “90% savings” from one synthetic run. Compare similar tasks using accepted results, context, routes, attempts, elapsed time, actual API charges and defects found.
