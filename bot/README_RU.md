# DSHREMBOT Local Preview

Это отдельный **самостоятельно запускаемый бот только для чтения**. Он отвечает владельцу `/status` сведениями о сервере, на котором запущен: uptime, нагрузка и свободное место. Он не имеет доступа к операторскому DSHREMBOT, Tvijo API, роутеру моделей, shell, SSH, рою агентов или платному биллингу. Для клиентского подключения к Tvijo используйте [заявку на пилот](https://tvijo.com/static/dshrem-platform-ru-20261018.html).

Требуется Node.js 22+ и новый Telegram-бот от [@BotFather](https://t.me/BotFather). Токен остаётся на **вашем** сервере.

```sh
cd bot
cp .env.example .env
chmod 600 .env
```

Откройте `.env` локальным редактором и вставьте токен BotFather в `DSHREM_BOT_TOKEN`. Не вставляйте его в командную строку, чат, issue или форму Tvijo. Пока оставьте `DSHREM_BOT_OWNER_ID` пустым. Запустите:

```sh
npm run pair
```

В течение пяти минут отправьте своему новому боту `/id` в личном чате. Он ответит вашим числовым Telegram ID и остановится. Впишите этот ID в `DSHREM_BOT_OWNER_ID` в `.env`, затем:

```sh
npm start
```

Отправьте `/start`, `/help` и `/status` в личном чате. Сообщения других людей и групп бот игнорирует. Если видите `telegram_http_409`, проверьте, что тот же BotFather-токен не используется другим polling/webhook процессом; второй потребитель не запускается. Для остановки процесса нажмите Ctrl+C. При утечке токена перевыпустите его через BotFather, измените `.env` и перезапустите бота.

Запуск в production требует отдельного системного пользователя, ограничений процесса и управления секретом по правилам вашей инфраструктуры. Этот preview не открывает удалённый доступ к серверу и не создаёт оснований для платного использования. Пакет наследует статус лицензии репозитория `UNLICENSED`; условия коммерческого распространения ещё не установлены.
