Сначала убедитесь, какой редактор и какое расширение действительно запущены.

Руководство для VSIX 0.10.14 и новее · 26 октября 2026

Используйте официальный выпуск и проверяйте активную версию после установки. У TvijoCode собственный номер сборки: сверяйте его в Help → About, а версию встроенного расширения — в Settings Tvijo. Если файл ещё недоступен в выпуске, публикация не завершена.

Скачать VSIX 0.10.14 ↓Выпуск TvijoCode для Windows ↗Описание и файлы выпуска ↗
Вариант А · У вас уже есть VS Code
  1. Получите опубликованный файл .vsix из официального выпуска Tvijo. Сверьте версию; при наличии SHA256 сравните контрольную сумму.
  2. Откройте Extensions → меню … → Install from VSIX…, выберите файл.
  3. В палитре команд Ctrl + Shift + P выполните Tvijo: Reload window. На macOS вместо Ctrl используется Cmd.
  4. Откройте Tvijo → Settings и проверьте активную версию. Старый процесс расширения может продолжать работать до перезагрузки.
Вариант Б · Отдельный TvijoCode на Windows
  1. Получите Windows-сборку из официального выпуска; сохраните свои настройки и незакоммиченные файлы.
  2. Установите или распакуйте сборку согласно формату скачанного архива. Откройте свой проект через File → Open Folder….
  3. Проверьте версию редактора в Help → About, затем версию расширения Tvijo в его Settings. Эти номера отличаются.
  4. Если VSIX установлен отдельно, перезагрузите окно и снова проверьте активную версию.

Проверка содержимого Windows-архива на Linux не заменяет запуск GUI на реальной Windows-машине.

В новом выпуске этот учебник открывается из палитры команд: Tvijo: Open learning guide. Для локального чтения руководства вход в сервис не нужен.

Первый вход и правильный каталог

  1. Откройте знакомый репозиторий. Подтвердите Workspace Trust только для проекта, которому доверяете.
  2. Вызовите Tvijo: Sign in. Подтвердите вход в браузере под нужной учётной записью; затем вернитесь в редактор. Ключи не вставляйте в чат.
  3. В Explorer нажмите правой кнопкой нужную папку → Work in Tvijo. Кнопка папки в чате показывает выбранный каталог; наведите курсор для полного пути.
  4. Вызовите Tvijo: Check service connection. Откройте Account and credit, если сервис сообщает об учётной записи или лимите.
  5. Откройте Settings → Select project context, оставьте только нужные исходники и тесты. Проверьте Tvijo: Preview bounded project context.
Локально или Remote SSH?

Обычное локальное окно использует ваш компьютер. Окно Remote SSH работает на удалённом хосте: там должны быть файлы, зависимости, расширение и необходимые команды. Смена активного файла не меняет выбранную папку Tvijo.

DSH Harness: когда нужен дополнительный Linux-хост

Для управляемых фоновых задач нужен настроенный Linux runtime. На Windows обычный Agent доступен отдельно; наличие VSIX не означает установленный Harness.

  1. Откройте подготовленный проект на Linux локально или через Remote SSH.
  2. Вызовите Tvijo: Set up orchestration, затем Tvijo: Orchestration doctor.
  3. Проверьте доступный профиль, вход в account CLI и остаток подписной квоты. Выбирайте Sol или Sol + Astra; Claude сейчас приостановлен оператором.
  4. Включайте Orchestration: Enabled только после успешной настройки. Подписные workers и API-координатор — разные пути расходов.

Недоступный маршрут не заменяйте молча другим провайдером. При исчерпанной подписке остановитесь; автоматический переход на API не разрешён.

Один маленький цикл — один результат 🔄

Агенту легче сделать узкую задачу до конца, чем угадывать, что означает «улучши весь проект».

1. План: дайте проверяемое задание

Выделите функцию или приложите один файл и сообщение об ошибке. Запустите Tvijo: Run agent in plan mode. Plan читает и объясняет; команды и изменения для этого запуска выключены.

Цель: [какое поведение нужно получить].
Сейчас: [ошибка + как её повторить].
Можно менять: [точные пути]. Не трогать: [ограничения].
Готово, когда: [2–3 наблюдаемых условия].
Проверка: [существующая узкая команда теста].
Сначала покажи причину и короткий план. Не меняй файлы.
Новое в 0.10.14: разобраться в коде через символы редактора

Попросите Agent или Plan: «Покажи символы этого файла», «Найди определение функции в этой позиции» или «Найди ссылки на этот символ». Инструмент code_intelligence вызывает установленные языковые провайдеры VS Code; для нужного языка требуется рабочее расширение и проект.

Возвращаются имена, типы символов и позиции, а не полный текст всех файлов. Строки и колонки считаются с 1. При недоступном провайдере приложите нужные файлы явно; пустой результат сам по себе не доказывает отсутствие использований.

Работаем в Plan. Для src/stats.py покажи список символов.
Для average на строке 12, колонке 5 найди определение и ссылки.
Это пример позиции: используй фактическую строку и колонку моего файла.
Не меняй код. Отдели результат провайдера от предположений.
Если провайдер недоступен или ответ частичный — скажи об этом явно.

Это интеграция редактора. Отдельный Python LSP-пилот на сервере не становится включённым из-за установки VSIX.

2. Правка: определите границы

После плана используйте Tvijo: Run agent task и подтвердите конкретное изменение. Для одной локальной правки подходит Tvijo: Quick edit the current file: результат остаётся буфером для просмотра и явного сохранения. Agent в Auto сохраняет допустимые изменения до последующих тестов.

Сначала посмотрите git status --short. Запишите, какие изменения уже существовали. Двум агентам дайте разные пути либо отдельные worktree. Не поручайте параллельно менять один файл.

3. Тест: докажите нужное поведение

Начните с теста изменённой функции или файла, затем выполните необходимые проверки репозитория. Если инструмент не может выполнить команду, запустите её в подходящем терминале и приложите результат через Tvijo: Attach observed terminal output. Для UI проверьте сценарий в браузере и узкий экран.

Зелёный синтаксис ≠ работающая функция. Диагностика редактора, тесты, сборка, установленный пакет и продакшен — отдельные доказательства. Запишите команду, код возврата, дату и версию.

4. Ревью: закройте задачу доказательствами

Проверь только diff этой задачи и её критерии готовности.
Ищи ошибки, регрессии и пропущенные граничные случаи.
Для замечания укажи файл, сценарий и проверяемое следствие.
Отдели доказанные ошибки от предположений.
Не исправляй файлы в этом проходе. Не запускай платный совет автоматически.

Метод Review from another role меняет подход к ответу; он сам по себе не запускает независимого агента. Отдельное ревью оправдано сложностью и риском задачи. После исправлений повторите затронутые проверки.

# Работа через Tvijo

Правила являются советами проекту и не предоставляют разрешения инструментам. Изменённые командами правила могут попасть в карантин; проверьте diff, затем явно включите нужный файл в Settings.

Экономный профиль расширения для общего рабочего дерева

Это рекомендация, а не значения по умолчанию. Изменяйте через Settings → Extension settings либо перенесите выбранные поля из Tvijo: Open configuration file example в User/Remote settings.

{
  "tvijo.model": "ds41f",
  "tvijo.agentModel": "ds41f",
  "tvijo.agentMode": "single",
  "tvijo.reasoningMethod": "plan-check",
  "tvijo.agentMaxSteps": 30,
  "tvijo.agentBudgetUsd": 2,
  "tvijo.workspaceContextMaxBytes": 48000,
  "tvijo.autoCommit": "off"
}

Заданный лимит — потолок, не обещанная цена. Число шагов ограничивает один запуск. В общем операторском задании нельзя складывать несколько локальных лимитов как новые разрешения на расход: действует общий root cap. Доступность модели проверяет сервис.

Что отличается в терминале DSHREM

Не переносите настройки расширения в CLI механически. Его автоматический загрузчик использует AGENTS.md и AGENTS.local.md; наличие .tvijo/rules.md не означает, что CLI его прочитал. Проверьте вывод справки установленной версии и приложенный контекст.

Для наших проектов сохраняются дополнительные правила: одна фаза за раз, точные пути изменения, исходный gate, артефакты на volume и никаких тяжёлых проверок на общем хосте. Текущий учебник их не отменяет.

Пустой список ломает среднее значение

Где работать: VS Code + VSIX или TvijoCode, папка небольшого Python-проекта. Выделите функцию average, приложите её тест и traceback. Начните с Plan.

В учебном проекте src/stats.py функция average([]) вызывает ZeroDivisionError.
Требование: пустой список возвращает None; average([2, 4]) возвращает 3.
Можно менять только src/stats.py и tests/test_stats.py.
Не менять зависимости, публичные имена и другие функции.
Сначала объясни причину и предложи минимальный план без записи.
После согласованного плана внеси правку и проверь оба случая.
Команда проекта: python -m unittest tests.test_stats
В конце покажи diff, команду и реальный результат.

Что проверить человеку: новый контракт None подходит вызывающему коду, старый непустой случай работает, тест действительно запускался после последней правки.

Небольшой фильтр задач

Где работать: редактор для кода; настроенный Linux Harness — если задача должна продолжаться после отключения ноутбука. Разделите реализацию и ревью на последовательные этапы.

Добавь в учебный список задач фильтр «Все / Выполненные / Активные».
Этап 1: только локальный UI, без API, базы данных и новых зависимостей.

Сначала прочитай текущий компонент и тесты, затем предложи план.
Используй существующую команду проверки именно этого компонента.
Остановись после этапа 1 с diff и результатами; другие этапы не начинай.

Что проверить человеку: фильтр не удаляет задачи, изменения статуса видны во всех режимах, пустой список не выглядит ошибкой.

Маршрут модели под задачу

Обычный chat/Agent по умолчанию использует ds41f. Для небольшой правки начните с доступного базового маршрута и узкого контекста. Для неоднозначной архитектуры сначала соберите факты, затем используйте один адресный разбор сильной моделью. Доступность и цена маршрута подтверждаются сервисом, а не названием в списке.

При повторении одинаковых неудачных попыток в наших проектах допускается одна консультация Codex GPT-6.1 Sol через account CLI с материалами AGENTJUDGE. Это совет по доказательствам, а не право расширить бюджет или утвердить собственные изменения. Claude остаётся приостановлен.

Подписка и API считаются отдельно.

Account CLI Codex работает в пределах подписной квоты и не является оплатой за каждый вызов. Запускайте его без OPENAI_API_KEY и ANTHROPIC_API_KEY, не подгружайте общий файл секретов. Подписка не делает API-вызовы сервиса бесплатными. При исчерпанной квоте API fallback не разрешён.

Лимит — не план расходов

Фактические defaults расширения: 60 шагов, $2, Auto. Экономный пример в главе «Правила проекта» уменьшает шаги до 30 и локальный контекст до 48 000 байт; его нужно применить явно. Уменьшайте денежный потолок под небольшую задачу, если нужный маршрут и объём в него помещаются.

Для текущих операторских задач общий API-потолок — $2 на root task, включая платных workers, если отдельно не задан иной предел. Увеличение локального лимита или новый запуск не обнуляют уже потраченное. Неизвестная стоимость — причина остановки платного пути, а не $0.

Просматривайте Tvijo: Recent tasks and spending и Tvijo: Service usage and receipts. TT — сервисный кредит, а model tokens — объём обработанного текста; это разные единицы.

Контекст: почему больше не всегда лучше

Локальный preview по умолчанию собирает до 200 000 байт; ограничение можно настроить. Сформированный excerpt запроса ограничен 60 000 байтами, а правила имеют отдельный предел. Больший preview не расширяет контекстное окно модели. Приложите явные файлы и проверьте финальный контекст.

Пока нет данных для сравнения. Неизвестные расходы не считаются нулём.

Когда агент остановился: сохраните, разберитесь, продолжите 🛟

Нужны последняя команда, наблюдаемая ошибка и сохранённый результат. Новая задача не должна стирать предыдущую.

Не та версия, не та папка или не те файлы

Проверьте Settings → активная версия и Tvijo: Reload window. Наведите курсор на кнопку папки: выполнение привязано к ней, не к последнему открытому файлу. Переключение каталога во время работы блокируется; сначала остановите задачу.

Если в контексте нет нужного файла, выберите его явно. Если нет правил, проверьте Workspace Trust, Context Off, переключатели и карантин в Settings.

Ошибка входа, соединения или доступного бюджета

Используйте Tvijo: Check service connection, затем Account and credit. Запишите точную ошибку без токенов. При неизвестной стоимости, отказе учётной записи или исчерпанной квоте не обходите остановку новым платным маршрутом.

Задача Harness пропала после отключения

На подготовленном Linux-хосте вызовите Tvijo: Orchestration status and repair queue, затем Tvijo: Resume orchestration task для исходной задачи. Проверяйте Orchestration doctor. Repair использует исходный ограниченный бюджет.

Доступный удалённый хост может продолжать задачу в tmux. Выключенный локальный компьютер продолжать её не может. Потеря интерфейса статуса ещё не доказывает, что задача завершена или потеряна.

Изменения неудачны: как использовать Rewind

Вызовите Tvijo: Rewind или /rewind. Выберите запуск и шаг; просмотрите затронутые файлы. Rewind восстанавливает файловые правки до шага, но не отменяет побочные эффекты shell-команд и внешних инструментов.

При конфликте с чужой или новой работой выбирайте Skip file. Не соглашайтесь на Overwrite file или Delete file без явного права на конкретные пути. Сначала сохраните обе версии и разберите diff. Контрольная точка не заменяет отдельную резервную копию и не живёт бесконечно.

Правила оказались в карантине

Команда изменила файл правил вне подтверждённой прямой правки. Такие правила исключаются из последующих запросов. Проверьте diff и происхождение изменения; только затем явно включите файл в Settings. Переход в дочернюю папку не снимает карантин.

Один и тот же неуспех повторяется

Остановите повторение. Сохраните текст задачи, diff, команду, вывод, код возврата, версию и расходы. Измените одну гипотезу или получите один адресный разбор. Не запускайте бесконечный рой и не активируйте Claude при действующей паузе.

Что означает «готово»

  1. Реализовано: есть конкретная версия кода и diff.
  2. Проверено: есть тесты и наблюдаемый сценарий с датой.
  3. Выпущено: есть скачиваемый пакет, номер версии и контрольная сумма.
  4. Работает у вас: установлен пакет, перезагружен процесс, выполнено первое безопасное задание.

Нельзя обещать «90% экономии» по одному синтетическому прогону. Ведите сопоставимые замеры: задача, контекст, модель, попытки, минуты до принятия, фактический API-расход и найденные ошибки.

Устройство этого руководства

Один автономный HTML, без внешних шрифтов, скриптов и аналитики. Поиск работает по главам. Прогресс остаётся в локальном хранилище браузера; расчёт времени и денег не сохраняется. Кнопка «Печатать» раскрывает все главы для PDF или бумаги.
